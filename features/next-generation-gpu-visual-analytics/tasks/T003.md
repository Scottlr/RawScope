### T003 - Refine Workbench Chrome And Dataset Identity

#### Objective

Turn the current egui shell into a restrained analytical workspace with a
compact icon-led toolbar, short dataset identity, collapsible inspector, and
clear hierarchy. Remove persistent full-path noise without weakening access to
source details or evidence.

#### Scope

- Split shell/layout behavior out of oversized `ui.rs` and `ui_controls.rs`
  into `ui_shell.rs` and `ui_dataset_identity.rs`.
- Add a UI-only `DatasetDisplayIdentity` projection with short filename,
  source kind, row count, optional profile label, and optional full path.
- Change the window title to `RawScope - <short name>` with no full path or
  density-stat dump.
- Replace persistent full path text with `<filename> - <rows> rows`; expose the
  full path through hover/details and a copy command.
- Make the right inspector collapsible with a stable icon button and retain its
  width while collapsed/expanded.
- Consolidate Reset, Clear, and Export into compact commands with tooltips.
- Add a Lucide icon source narrowly: prefer `iconflow` with
  `default-features = false, features = ["pack-lucide"]` after confirming
  compatibility with the current Rust/egui versions. Do not enable all packs.
- Keep Scatter, Timeline, Missingness, and Dataset Diff as predictable tabs.

#### Out Of Scope

- No landing page, tutorial overlay, command palette, docking system, arbitrary
  panels, theme editor, or general component framework.
- No interaction-mode controls; T004 adds Pan/Brush/Inspect to the toolbar.
- No filter shelf; T008 owns it.
- No axis or renderer changes beyond consuming T001 layout.

#### Blocked By

T001.

#### Why It Is Blocked

The refined shell must reserve and return the authoritative plot surface rather
than reproducing the current implicit central region.

#### Implementation Details

Create UI-only identity types:

```rust
#[derive(Debug, Clone, PartialEq, Eq)]
pub(crate) struct DatasetDisplayIdentity {
    pub(crate) short_name: String,
    pub(crate) source_label: String,
    pub(crate) row_count: usize,
    pub(crate) profile_label: Option<String>,
    pub(crate) full_path: Option<std::path::PathBuf>,
}

#[derive(Debug, Clone, Copy, PartialEq, Eq, Default)]
pub(crate) enum InspectorState {
    Collapsed,
    #[default]
    Expanded,
}

#[derive(Debug, Clone, Copy, PartialEq, Eq, Default)]
pub(crate) struct WorkbenchShellState {
    pub(crate) inspector: InspectorState,
}
```

Projection rules:

- Local CSV/Parquet: `short_name` is `path.file_name()` with a safe fallback.
- Synthetic: a concise generator name, not a fake file path.
- `source_label` is `CSV`, `Parquet`, or `Synthetic`.
- Format counts with separators in visible UI (`200,000 rows`).
- Full path appears only in tooltip/details/copy action, never title or
  persistent toolbar/status text.

Extend `UiActions`:

```rust
pub(crate) struct UiActions {
    // existing fields
    pub(crate) toggle_inspector: bool,
    pub(crate) copy_dataset_path: bool,
}
```

Move top/right/bottom panel assembly to `ui_shell.rs`. The right rail should use
one stable expanded width and a narrow collapsed strip; it must not become a
card nested inside another card. Use icon-only buttons for familiar Reset,
Clear, Export, Copy, and inspector collapse commands, each with an accessible
hover tooltip. Tabs may retain icon+text because they switch primary views.

If the icon dependency is approved, add exactly:

```toml
iconflow = { version = "1.0.0", default-features = false, features = ["pack-lucide"] }
```

Confirm the current crate API and lockfile result before using this literal
version; if a compatible patch supersedes it, record the chosen version in the
handoff. Do not add `egui-elegance`, `egui-shadcn`, or another UI framework.

The status bar should contain visible x/y ranges, active cohort count, and
export state. It should not repeat the entire dataset path, grid config, or
selection prose already visible in the inspector.

#### Migration Notes

- UI-only state changes require updating `WorkbenchUiState` tests.
- Keep CLI output/errors unchanged.
- Do not alter v1/v2/v3 evidence path serialization.
- Move functions before adding styling so the diff separates ownership from
  visual changes.

#### Misinterpretations To Prevent

- Wrong interpretation: remove the source path everywhere.
  Correct rule: remove persistent chrome exposure; retain details/evidence.
- Wrong interpretation: build a new design system crate.
  Correct rule: keep focused egui helpers in the workbench.
- Wrong interpretation: use rounded cards for every section.
  Correct rule: use unframed sections and one right inspector rail.
- Wrong interpretation: enable an icon mega-pack.
  Correct rule: only Lucide, or stop for review.

#### Invariants

- Persistent UI and window title never include the full local path.
- Dataset filename and row count remain visible in the first viewport.
- Collapsing the inspector expands T001 plot geometry immediately.
- Commands retain tooltips and disabled states.
- Existing surfaces and report actions remain reachable.
- `ui.rs` and `ui_controls.rs` shrink rather than grow.
