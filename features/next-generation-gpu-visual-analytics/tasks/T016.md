### T016 - Curate The Flagship Lichess Visual Workbench

#### Objective

Turn the completed contracts into one coherent flagship workflow on the real
external 200,000-game Lichess dataset. Curate defaults and option order, fix
integration inconsistencies, and verify analytical truth without hiding new
architecture in a final catch-all task.

#### Scope

- Extend the Lichess profile with final human-reviewed presentation defaults
  using contracts already introduced by prior tasks.
- Curate first-view identity, axes, equality guide, density presentation,
  interaction default, filter ordering, projection option, point reveal,
  difference mode availability, relief controls, and inspector hierarchy.
- Add a small deterministic Lichess-shaped test fixture only if needed for
  profile/filter/projection behavior; do not copy rows from the external source
  unless redistribution is clearly permitted.
- Run the real native workbench against the external 200,000-row profile CSV
  and exercise the complete workflow.
- Fix only integration defects inside existing owners; split any newly
  discovered architectural requirement into a new task.
- Record exact manual command, dataset row count, adapter, checks, and visual
  review outcomes in the implementation handoff without making a benchmark
  claim.

#### Out Of Scope

- No dataset downloader, converter, embedded 29.6 MB profile CSV, 343 MB source,
  license claim, public benchmark, marketing copy, or online service.
- No new visual mode, filter predicate, evidence version, layout framework, or
  shader architecture.
- No broad timeline parity project or generic dataset-specific scripting.
- No screenshot/window-open test.

#### Implementation Details

If prior tasks do not already expose profile defaults, add the narrow data-owned
contract anticipated here:

```rust
#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub struct ScatterDatasetProfileDefaults {
    pub show_equality_guide: bool,
    pub suggest_mean_difference: bool,
    pub preferred_filter_columns: &'static [&'static str],

```

Do not put render enum values in `rawscope-data`. Workbench maps these semantic
hints to current render defaults:

- start in RawXY;
- TopographicField remains the initial presentation unless human review
  explicitly approves ReliefField as equally readable/truthful;
- show equality guide in RawXY;
- offer Mean/Difference adjacent to Raw;
- default persistent interaction mode Pan;
- point reveal Auto;
- no active filter and AbsoluteDensity on load;
- expand winner/category/time-control filters before lower-priority fields;
- keep relief advanced controls collapsed;
- keep inspector expanded at 1280x720 and remember user collapse state.

   overlay alignment.
10. Toggle reduced motion and repeat a mode/filter change.
11. Export v4 and inspect JSON/Markdown/manifest for complete query context.

This sequence is manual product acceptance, not an automated window/screenshot
test. Do not report frame rate or throughput unless a separately approved
benchmark is run under repository policy.

Option curation rules:

- Primary toolbar: view tabs, Pan/Brush/Inspect, Reset, inspector toggle, Export.
- Right inspector order: Visual Encoding, Filters, Pinned Inspection,
  Selection Comparison, Selected Rows.
- Normal visible options: projection, absolute/difference, cells/topographic/
  relief, linear/log1p, point Auto/Off, active filters.
- Advanced disclosure: relief strength/azimuth and any non-default technical
  choice approved by prior tasks.
- Do not expose grid buffer sizes, workgroup sizes, shader sample counts, mask
  revisions, or transition revisions.
