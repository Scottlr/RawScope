### T004 - Add Explicit Pan Brush And Inspect Modes

#### Objective

Replace hidden gesture knowledge with an explicit, efficient interaction model.
Pan, Brush, and Inspect become stable modes with cursor feedback, familiar
shortcuts, and temporary modifier overrides while preserving finalized
data-space selections.

#### Scope

- Create `apps/rawscope-workbench/src/app_interaction_mode.rs` for mode state,
  temporary overrides, and cursor selection.
- Add Pan, Brush, and Inspect segmented icon controls to the T003 toolbar.
- Route winit mouse events only when they start inside T001 plot geometry.
- Preserve gesture ownership through egui-consumed move/release events.
- Set `Grab`/`Grabbing`, `Crosshair`, and inspection cursor feedback.
- Keep right-drag as a temporary Brush override and Shift+left as Brush for
  compatibility; release returns to the selected persistent mode.
- Add keyboard shortcuts `H` (Pan), `B` (Brush), and `I` (Inspect) when egui is
  not editing text.
- Make Inspect immediately useful in this task by projecting the hover cursor
  to exact current data x/y coordinates and showing those coordinates in the
  quiet status bar. T009 later adds bin counts, row samples, and pinning.
- Ensure Escape cancels an in-progress gesture first, then clears a finalized
  selection on a subsequent press.

#### Out Of Scope

- No density count, row tooltip, or pinning; T009 enriches the coordinate-only
  Inspect behavior.
- No filter controls or focus-selection action; T008 owns filters.
- No gesture customization UI, keymap editor, touch gestures, or inertia.
- No timeline feature expansion beyond preserving current pan/brush behavior.

#### Blocked By

T001 and T003.

#### Why It Is Blocked

Mode routing requires authoritative plot hit-testing and the refined toolbar.

#### Implementation Details

Add app-owned enums:

```rust
#[derive(Debug, Clone, Copy, PartialEq, Eq, Default)]
pub(crate) enum WorkbenchInteractionMode {
    #[default]
    Pan,
    Brush,
    Inspect,
}

#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub(crate) enum ActivePointerGesture {
    Pan,
    ScatterBrush,
    TimelineBrush,
    Inspect,
}

#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub(crate) enum InteractionOverride {
    ShiftBrush,
    SecondaryButtonBrush,
}

#[derive(Debug, Clone, Copy, PartialEq)]
pub(crate) struct InspectCursorPosition {
    pub(crate) x: f32,
    pub(crate) y: f32,
}
```

`WorkbenchApp` stores:

```rust
pub(crate) interaction_mode: WorkbenchInteractionMode,
pub(crate) active_pointer_gesture: Option<ActivePointerGesture>,
pub(crate) interaction_override: Option<InteractionOverride>,
```

Do not derive gesture state indirectly from three optional drag fields after
this task. Existing per-view drag data remains, but `active_pointer_gesture` is
the routing source of truth.

Add to `UiActions`:

```rust
pub(crate) set_interaction_mode: Option<WorkbenchInteractionMode>,
```

Toolbar controls are a compact segmented group using Lucide Hand, Scan/Box
Select, and Search/Crosshair equivalents from the approved pack. Labels belong
in tooltips, not persistent instructional prose.

Event rules:

1. On press, reject plot gestures if cursor is outside `PlotRectPx`.
2. Right press or Shift+left starts Brush regardless of persistent mode.
3. Otherwise left press starts the persistent mode.
4. Once active, process pointer moves even if egui marks them consumed.
5. Always process the matching release and clear override/active gesture.
6. Pointer movement outside the plot may update a pan/brush already in progress;
   geometry clamps fractions as specified by T001.
7. Inspect hover maps the current plot fraction through the active viewport and
   updates `InspectCursorPosition`; leaving the plot clears it.

Cursor rules:

- Pan hover: `Grab`; active: `Grabbing`.
- Brush: `Crosshair`.
- Inspect: `Crosshair` or approved inspect cursor.
- Outside plot or over UI: egui/default cursor.

#### Before / After

**Before:**

```rust
MouseButton::Left | MouseButton::Middle => self.begin_pan(),
MouseButton::Right => self.begin_brush(),
```

**After:**

```rust
let gesture = self.resolve_pointer_gesture(button, self.modifiers);
self.begin_pointer_gesture(gesture, position);
```

#### Migration Notes

- Default mode is Pan, preserving current left-drag behavior.
- Shift+left and right-drag brush remain supported.
- Existing keyboard Reset/Export shortcuts remain unless they conflict with
  text input; update routing tests accordingly.
- No evidence schema changes; interaction mode is transient UI state.

#### Misinterpretations To Prevent

- Wrong interpretation: make Inspect a placeholder button that does nothing
  forever.
  Correct rule: this task wires real routing state; T009 consumes it.
- Wrong interpretation: remove existing modifier shortcuts.
  Correct rule: preserve them as temporary overrides.
- Wrong interpretation: let egui consume a release after a gesture starts.
  Correct rule: active pointer ownership survives until release/cancel.
- Wrong interpretation: show visible usage instructions on the canvas.
  Correct rule: use familiar cursors and tooltips.

#### Invariants

- Exactly one persistent interaction mode is active.
- At most one pointer gesture is active.
- A gesture cannot start over the toolbar/inspector/status bar.
- Active gestures always terminate on matching release or Escape.
- Default left drag remains the user-approved pan behavior.
- Finalized selections stay data anchored.
