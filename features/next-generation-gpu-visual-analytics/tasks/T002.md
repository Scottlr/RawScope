### T002 - Add Refined Axes Grid And Dataset Guides

#### Objective

Make axes feel native to the plot: stable gutters, readable nice-number ticks,
subtle clipped grids, concise labels, and truthful dataset guides. Remove the
fixed overlay guard model completely.

#### Scope

- Extend `crates/rawscope-render/src/view_axes.rs` with bounded nice-tick
  generation and explicit value-format contracts for scatter/timeline axes.
- Add equality and zero reference-guide contracts for scatter projections.
- Create `apps/rawscope-workbench/src/ui_plot_axes.rs` and move axis painting
  out of oversized `ui_view_context.rs`.
- Draw axes and grids against T001 `PlotSurfaceLayout.logical_rect`.
- Reserve stable logical gutters in the central plot allocation rather than
  painting labels over data.
- Format Lichess ratings without trailing `.0`; compact large values only when
  labels would otherwise collide.
- Keep timeline integer behavior unless a profile explicitly supplies a time
  format in a later feature.

#### Out Of Scope

- No generic charting-axis library, secondary axes, logarithmic coordinate
  scales, free-form style editor, or date library.
- No profile-hint additions; T005 owns those contracts.
- No residual projection implementation; T011 consumes the zero guide.
- No visual shell restyle; T003 owns chrome.

#### Blocked By

T001.

#### Why It Is Blocked

Axes, grids, and guides must use the authoritative plot rectangle instead of
reintroducing separate margin calculations.

#### Implementation Details

Add bounded render-owned contracts:

```rust
#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub enum AxisValueFormat {
    Integer,
    Decimal { max_fraction_digits: u8 },
    Compact,
}

#[derive(Debug, Clone, Copy, PartialEq)]
pub enum ScatterReferenceGuideKind {
    Equality,
    Horizontal { y: f32 },
    Vertical { x: f32 },
}

#[derive(Debug, Clone, PartialEq)]
pub struct ScatterReferenceGuide {
    pub kind: ScatterReferenceGuideKind,
    pub label: String,
}
```

Preserve the existing public helper as a compatibility wrapper and add an
explicit options path without a generic style DSL:

```rust
#[derive(Debug, Clone, PartialEq)]
pub struct ScatterAxesOptions {
    pub target_tick_count: usize,
    pub x_format: AxisValueFormat,
    pub y_format: AxisValueFormat,
    pub guides: Vec<ScatterReferenceGuide>,
}

pub fn scatter_axes_context_with_options(
    x_range: F32Range,
    y_range: F32Range,
    x_label: impl Into<String>,
    y_label: impl Into<String>,
    options: ScatterAxesOptions,
) -> ScatterAxesContext;
```

Keep the existing `scatter_axes_context(..., max_ticks)` signature and implement
it as a wrapper using Decimal defaults and no guides. Update new workbench code
to call `scatter_axes_context_with_options()`.

Nice ticks use a `1, 2, 5 * 10^n` step, include values inside the visible range,
remain deterministic for negative/overscrolled ranges, and target 4-7 ticks.
Never create more than `MAX_AXIS_TICKS = 9`. Handle tiny spans without NaN,
infinity, or duplicate labels.

Create app-owned layout constants with units:

```rust
pub(crate) const PLOT_LEFT_GUTTER_POINTS: f32 = 58.0;
pub(crate) const PLOT_BOTTOM_GUTTER_POINTS: f32 = 38.0;
pub(crate) const PLOT_TOP_GUTTER_POINTS: f32 = 10.0;
pub(crate) const PLOT_RIGHT_GUTTER_POINTS: f32 = 12.0;
```

`ui_plot_surface.rs` reserves these gutters and returns the data rectangle.
`ui_plot_axes.rs` paints ticks/grid/guides in a foreground layer but allocates
no interactive widgets. Grid lines use a low-contrast stroke and are clipped to
the plot. Guide lines are visually distinct from grid and brush overlays.

Equality guide endpoints must be clipped in data space to the intersection of
x/y visible ranges, then projected into the plot. A horizontal zero guide is
used by T011 mean/difference projection. If a guide lies outside the viewport,
do not draw or label it.

#### Migration Notes

- Remove all `AXIS_OVERLAY_*_GUARD_PX` constants and `overlay_area()`.
- Keep bottom status labels as a concise fallback until T003 refines them.
- Preserve deterministic existing axis tests, adjusting expected labels only
  where nice ticks intentionally replace evenly spaced decimals.
- No serialized evidence changes.

#### Misinterpretations To Prevent

- Wrong interpretation: add a full plotting library.
  Correct rule: retain RawScope-specific scatter/timeline context structs.
- Wrong interpretation: stretch the data rectangle to make room after T001.
  Correct rule: gutters are reserved before physical plot conversion.
- Wrong interpretation: always draw the equality line.
  Correct rule: only profiles/projections that request it provide that guide.
- Wrong interpretation: use dense bright grid lines for visual impact.
  Correct rule: grids support reading and remain subordinate to density.

#### Invariants

- Axis ticks and grids align to the exact T001 plot rectangle.
- Tick values are monotonic, finite, bounded, and have unique visible labels.
- Grid/guide painting consumes no pointer events.
- Equality/zero guides represent exact data-space equations.
- Ratings do not display meaningless trailing decimals.
- Narrow windows reduce tick count before labels overlap plot content.
