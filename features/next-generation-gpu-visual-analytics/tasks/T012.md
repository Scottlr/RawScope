### T012 - Add Normalized Difference Density Mode

#### Objective

Show where the active filtered cohort is proportionally over- or
under-represented relative to the full dataset. Compute a signed normalized
share delta per bin and render it with a zero-centered diverging palette.

#### Scope

- Create `crates/rawscope-render/src/difference_density.rs` for CPU reference
  math, configuration, stats, and errors.
- Add GPU baseline and active count buffers using T007 resident resources and
  T008 filter mask.
- Create a focused difference-density WGSL presentation path.
- Add `AbsoluteDensity` and `FilteredDifference` visual modes; disable the
  latter when no filter is active or either cohort total is zero.
- In FilteredDifference, use the dedicated signed field presentation, force
  point-reveal blend to zero, and disable Cells/Topographic/Relief surface
  controls. Preserve and restore the previous absolute presentation when the
  analyst returns to AbsoluteDensity.
- Use normalized cohort shares, a symmetric max-absolute domain, neutral zero,
  and a perceptually restrained diverging palette.
- Expose baseline/active totals and meaning in the encoding inspector.
- Keep brush/inspection coordinates unchanged; T009 inspection reports both
  active and baseline bin counts when difference mode is active.

#### Out Of Scope

- No arbitrary pair of cohorts, multi-class color, statistical significance,
  z-score, regression, or comparison-dataset diff in this task.
- No raw-count subtraction between unequal cohort sizes.
- No filter engine changes, timeline mode, or evidence v4.
- No public performance claim.

#### Implementation Details

Add explicit mode/config:

```rust
#[derive(Debug, Clone, Copy, PartialEq, Eq, Default)]
pub enum ScatterDensityMode {
    #[default]
    AbsoluteDensity,
    FilteredDifference,
}

#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub enum DifferencePalette {
    TealNeutralCoral,
}

#[derive(Debug, Clone, Copy, PartialEq)]
pub struct DifferenceDensityConfig {
    pub palette: DifferencePalette,
    pub clamp_percentile: Option<f32>,
}

impl Default for DifferenceDensityConfig {
    fn default() -> Self {
        Self { palette: DifferencePalette::TealNeutralCoral,
               clamp_percentile: None }
    }
}
```

The first implementation does not expose percentile clamp in the main UI. If
the field is retained for future use, only `None` is accepted until a tested
percentile contract exists; removing the field is preferable to dead config.

CPU reference:

```rust
pub fn normalized_difference_density(
    baseline_counts: &[u32],
    active_counts: &[u32],
    baseline_total: u64,
    active_total: u64,
) -> Result<DifferenceDensityGrid, DifferenceDensityError>;
```

For bin `i`:

```text
baseline_share = baseline_counts[i] / baseline_total
active_share   = active_counts[i] / active_total
delta          = active_share - baseline_share
```

The render domain is `[-max_abs_delta, +max_abs_delta]`. Zero maps to the
neutral midpoint. Positive means over-represented in active filter; negative
means under-represented. Empty/empty bins are exactly zero. Reject mismatched
grid lengths and zero totals before enabling the mode.

GPU path maintains/reuses:

- baseline counts (all-ones mask, recompute on viewport/projection revision);
- active counts (current mask, recompute on viewport/filter/projection revision);
- one GPU max-absolute fixed-point value over normalized deltas;
- totals as uniforms.

Do not read both count grids to CPU per frame. Because WGSL atomics do not
support `f32`, add a bounded reduction compute pass that converts
`abs(delta)` to fixed-point `u32` with
`DIFFERENCE_FIXED_POINT_SCALE = 1_000_000_000u`, clamps to `u32::MAX`, and uses
`atomicMax`. The fragment shader converts the maximum back to `f32`, calculates
share delta from both u32 count buffers and totals, and normalizes symmetrically.
CPU reference tests must prove fixed-point error stays within
`1.0 / DIFFERENCE_FIXED_POINT_SCALE` plus f32 tolerance. Keep Cells
presentation exact; Topographic/Relief may consume the signed field only after
their semantics are explicitly implemented. In this task, difference mode has
an exact diverging field plus optional contours, not sequential topographic
shading pretending to be signed.

Inspection hit extends with optional comparison:

```rust
pub struct DifferenceInspection {
    pub baseline_count: u32,
    pub active_count: u32,
    pub baseline_share: f64,
    pub active_share: f64,
    pub delta: f64,
}
```

UI legend labels negative/neutral/positive and includes cohort totals. Never
label color endpoints as raw row counts.

#### Before / After

**Before:**

```text
Color = log1p(active bin count) / viewport max.
```

**After difference mode:**

```text
Color = active cohort share - full baseline share, centered at zero.
```

#### Migration Notes

- AbsoluteDensity remains default and preserves current sequential encoding.
- Difference mode is disabled without a non-empty active filter.
- Difference mode temporarily suppresses point reveal and absolute surface
  presentation without mutating their saved settings.
- Add new contracts rather than changing existing density encoding labels.
- No evidence shape change until T015.

#### Misinterpretations To Prevent

- Wrong interpretation: subtract raw counts.
  Correct rule: subtract normalized cohort shares.
- Wrong interpretation: normalize positive and negative sides independently.
  Correct rule: one symmetric max-absolute domain centered at zero.
- Wrong interpretation: reuse the sequential palette.
  Correct rule: explicit diverging palette with neutral midpoint.
- Wrong interpretation: enable with no active filter.
  Correct rule: mode requires distinct non-empty active cohort.

#### Invariants

- Identical active/baseline distributions produce zero in every bin.
- Deltas sum approximately zero across a complete shared viewport, subject to
  floating-point tolerance and rows outside the viewport.
- Positive/negative colors have equal magnitude around zero.
- Absolute mode remains unchanged.
- Difference mode never renders Relief or point glyphs.
- Inspection and legend use the same formula/totals as the shader.
- Buffer/grid dimensions always match.

## Final Notes

- Recommended implementation order: CPU math, mode contract, dual buffers,
  shader/reduction, inspection, UI/legend.
- Unresolved questions: final diverging palette values require human review.
- Risks: misleading normalization and stale baseline viewport revisions.
- Human review: neutral readability, colorblind distinction, and legend copy.
- Completion: implemented on `codex/t012-normalized-difference-density`; active
  filters can now be compared with the full dataset through exact normalized
  share deltas and one symmetric zero-centered teal/neutral/coral GPU domain.
- Architectural decisions: render owns CPU reference/inspection math, fixed
  point encoding, two resident count states, max-absolute reduction, and the
  dedicated exact shader. Workbench owns baseline-dirty scheduling and mode
  compatibility. Filter-only revisions update only the active field; viewport,
  projection, and dataset revisions refresh both fields.
- Validation: 46 render unit tests plus integrations, 89 workbench tests, all
  data tests, the ignored `gpu_difference_matches_cpu_reference` adapter test,
  `cargo fmt --all --check`, and `cargo check --workspace` passed. Native review
  on 200,000 Lichess rows with a 94,504-row winner cohort used AMD Radeon RX
  7800 XT/Vulkan and verified signed colors, dark neutral zero, truthful totals,
  point suppression, and exact Absolute-mode restoration.
- Not run: no screenshot/startup/window test, benchmark, public timing claim,
  or broad adapter-test sweep was added or run.
- Remaining risk: a single extreme bin sets the symmetric domain because the
  deliberately unimplemented percentile clamp was removed rather than exposed
  as dead configuration. A future robust-domain option needs its own tested
  statistical contract.
