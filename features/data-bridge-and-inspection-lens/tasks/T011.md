### T011 - Add Evidence V5 Session And Inspection Context

#### Objective

Extend scatter evidence additively so an exported pinned region records the
local session provenance and the same exact/share/neighborhood/difference/sample
semantics shown in the workbench.

#### Scope

- Add `ScatterSelectionEvidenceV5`, its validation, JSON artifact DTO, Markdown
  formatter, schema documentation, report writer, manifest routing, and app
  projection.
- Preserve all v1-v4 types, methods, constants, JSON shapes, and report methods.
- Add optional session context: artifact kind/schema, display name, data format,
  and evidence-key column. Do not duplicate full data row corpus.
- Add rich pinned inspection context: exact cell/ranges/count/share,
  occupied-cell percentile, fixed neighborhood radius/count/share, optional
  difference explanation/strength percentile, bounded row IDs, sample limit,
  and bounded natural key values.
- Make v5 the default new scatter report while leaving explicit legacy routes.
- Keep transient UI state out of artifacts.

#### Out Of Scope

- No timeline v4/v5, full workspace/session serialization, screenshot capture,
  all-row export, source file hashing, upload, or evidence signing.
- No change to the v1 session manifest.

#### Blocked By

T003, T006, T007, T010.

#### Why It Is Blocked

Evidence needs stable session context, finalized summary definitions, and the
truthfully labeled pin payload before freezing schema v5.

Core additions:

```rust
pub struct ScatterSelectionEvidenceV5 {
    pub schema_version: u32,
    // retain v4 semantic fields
    pub session_context: Option<SessionEvidenceContextV5>,
    pub pinned_inspection: Option<PinnedScatterInspectionEvidenceV5>,
}

pub struct SessionEvidenceContextV5 {
    pub session_artifact_kind: &'static str,
    pub session_schema_version: u32,
    pub display_name: Option<String>,
    pub data_format: SessionDataFormatEvidenceV5,
    pub evidence_key_column: Option<String>,
}

pub struct PinnedScatterInspectionEvidenceV5 {
    pub bin_x: u32,
    pub bin_y: u32,
    pub x_range: F32Range,
    pub y_range: F32Range,
    pub row_count: u32,
    pub active_share: f64,
    pub occupied_density_percentile: Option<f64>,
    pub neighborhood_radius_bins: u32,
    pub neighborhood_row_count: u64,
    pub neighborhood_share: f64,
    pub difference: Option<PinnedDifferenceInspectionEvidenceV5>,
    pub row_id_sample: Vec<RowId>,
    pub sample_limit: usize,
    pub evidence_key_values: Vec<String>,
}
```

Use evidence-local enums/DTOs for session format and difference direction; do
not make `rawscope-render` depend on app state. `from_v4` or `from_v4_context`
must copy all v4 fields and validate additions.

Validation:

- schema version is exactly 5;
- all shares/percentiles are finite and in `0..=1`;
- neighborhood radius is exactly one for this schema;
- neighborhood count is at least exact row count and no greater than active
  cohort row count;
- row/key samples do not exceed sample limit or exact row count;
- key values require a session evidence-key column and cannot outnumber sampled
  rows;
- difference presence matches density mode and reuses formula/baseline ids;
- difference counts/shares/delta/direction are coherent with cohort totals;
- no session context is emitted for direct/synthetic startup.

Artifact JSON uses explicit snake_case names and `skip_serializing_if` only for
optional session/difference/percentile values. Do not flatten new fields into v4
or reuse the v4 artifact kind.

Markdown labels occupied-cell and difference-strength percentiles explicitly,
and labels row/category/key values as bounded samples. Manifest identifies v5.
Add `EvidenceReportBundlePaths::write_scatter_v5`. Update
`WorkbenchApp::export_selection_evidence` to build v5 from the successfully
projected v4 context, prefer `write_scatter_v5`, then retain its current
v4/v3/v2 fallbacks. Named v1-v4 writer methods remain unchanged.

#### Before / After

**Before:** v4 knows a pinned cell count/range/sample but not the session bridge
or richer analytical meaning.

**After:** v5 can reproduce what the user was told about the pinned region and
how the local bridged data was identified.

#### Migration Notes

- Additive version only. Do not edit legacy artifact DTOs or golden strings.
- Existing consumers requesting v4 continue receiving exactly v4.
- New default report manifests move to evidence schema 5.

#### Misinterpretations To Prevent

- Wrong: mutate v4 to save duplication. Correct: create v5 files/types.
- Wrong: serialize `ActiveSessionContext` directly. Correct: project to DTO.
- Wrong: include manifest/full data paths by default. Correct: source identity
  compatibility remains in existing dataset identity; session context is terse.
- Wrong: serialize hover/placement/alpha. Correct: pinned analytical truth only.
- Wrong: imply sampled key/category values are complete. Correct: label sample.

#### Invariants

- v1-v4 byte-level fixture outputs remain unchanged.
- v5 pinned metrics match the same immutable app summary shown at pin time.
- Session context is optional and local-only.
- Serde/evidence serialization remains in `rawscope-render`.
