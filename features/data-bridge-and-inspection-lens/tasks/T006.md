### T006 - Add Truthful Inspection Context Summaries

#### Objective

Make each settled inspection hit explain its exact cell, share of the active
cohort, density position among occupied cells, and bounded local neighborhood
without adding pointer-time scans or changing rendered density truth.

#### Scope

- Extend the render-owned inspection cache with settled-grid distribution data.
- Add an exact `ScatterInspectionSummary` derived from a hit and grid.
- Report exact count/ranges, active cohort share, tie-inclusive occupied-cell
  density percentile, and one-bin-radius neighborhood count/share.
- Keep hover lookup O(1) plus at most nine bin reads.
- Preserve deterministic bounded row samples and current y-axis mapping.
- Make empty-cell semantics explicit.

#### Out Of Scope

- No difference-mode interpretation; T007 owns it.
- No tooltip layout, animation, WGPU highlight, source-row scan, category
  aggregation, pin UI, evidence serialization, or configurable radius.
- No GPU count readback beyond the existing settled workflow.

#### Implementation Details

Add grid metadata:

```rust
#[derive(Debug, Clone, PartialEq, Eq)]
pub struct ScatterInspectionDistribution {
    pub included_row_count: usize,
    pub occupied_bin_count: u32,
    count_histogram: Vec<(u32, u32)>,
}

#[derive(Debug, Clone, PartialEq)]
pub struct ScatterInspectionSummary {
    pub hit: ScatterInspectionHit,
    pub active_share: f64,
    pub occupied_density_percentile: Option<f64>,
    pub neighborhood_radius_bins: u32,
    pub neighborhood_count: u64,
    pub neighborhood_share: f64,
}
```

The histogram stores sorted `(count, number_of_bins_with_count)` entries for
occupied cells only and is built once after binning. It must not store 65,536
sorted per-bin copies if a compact histogram suffices.

Required API:

```rust
impl ScatterInspectionGrid {
    pub fn summarize_hit(
        &self,
        hit: ScatterInspectionHit,
    ) -> ScatterInspectionSummary;
}
```

Definitions:

- `active_share = hit.count / included_row_count`, or 0 when total is zero.
- percentile is `occupied bins with count <= hit.count / occupied bins`.
- percentile is `None` when `hit.count == 0` or no occupied bins exist.
- neighborhood radius is the constant `INSPECTION_NEIGHBORHOOD_RADIUS_BINS = 1`.
- neighborhood includes the exact cell and clips at grid edges.
- neighborhood count uses `u64` accumulation and share uses the same active
  total.

Do not copy `row_ids` when projecting summaries; continue sharing the `Arc`.
The app state should retain summary rather than recomputing it during egui
painting. Rebuild/clear rules remain tied to settled viewport/filter revisions.

#### Before / After

**Before:** a hover knows only exact count/range and bounded row IDs.

**After:** it can truthfully say, for example, "842 rows, 0.85% of active rows,
96th percentile among occupied cells; 1,430 rows in the surrounding 3x3 area."

#### Migration Notes

- Existing `inspect_bin`/`inspect_fraction` remain callable.
- The summary type is additive; no serialized artifact changes.

#### Misinterpretations To Prevent

- Wrong: percentile across rows. Correct: rank across occupied grid cells.
- Wrong: neighborhood is another selection. Correct: contextual metric only.
- Wrong: scan neighboring source rows. Correct: sum at most nine cached counts.
- Wrong: rebuild per pointer event. Correct: distribution is settled-cache data.

#### Invariants

- Exact count/range remains the primary fact and matches the addressed bin.
- Neighborhood never leaves the current grid or double-counts a bin.
- Summary filter/viewport revision is the same as its hit/grid.
- Pointer work is bounded independently of dataset size.

#### Acceptance Criteria

- [ ] Shares use exact active totals and handle zero safely.
- [ ] Percentiles are deterministic, tie-inclusive, and occupied-cell-only.
- [ ] Center/edge/corner neighborhoods return correct bounded sums.
- [ ] Row sample and y-axis behavior remain unchanged.
- [ ] App hover consumes only current settled summaries.
