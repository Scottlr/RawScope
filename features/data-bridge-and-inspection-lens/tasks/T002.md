### T002 - Add Dataset Evidence Key Validation

#### Objective

Allow a session to name a natural source identifier such as `game_id`, validate
that it can identify loaded rows, and retain it as evidence metadata without
changing RawScope's dense internal row identity.

#### Scope

- Add a reusable `rawscope-data` evidence-key contract.
- Resolve a requested key against `LoadedSourceTable.columns`.
- Scan loaded rows once to reject missing, blank, or duplicate key values.
- Expose O(1) key lookup for a retained source row after validation.
- Keep key values as source strings so numeric and textual identifiers retain
  their exact decoded representation.

#### Out Of Scope

- No replacement or remapping of `rawscope_core::RowId`.
- No compound keys, generated hashes, file fingerprints, fuzzy uniqueness,
  database constraints, serializers, CLI/session wiring, or UI.
- No unconditional scan when no evidence key was requested.

#### Blocked By

None.

#### Why It Is Blocked

This pure data contract can be implemented independently. T003 later connects
the optional manifest field to it.

#### Related Code

- `crates/rawscope-data/src/local_dataset.rs` - `LoadedSourceTable::row` and
  dense ordinal row layout.
- `crates/rawscope-data/src/visual_record.rs` - visual records keyed by `RowId`.
- `crates/rawscope-data/src/dataset_filter.rs` - one-to-one row/mask alignment.
- Evidence row samples in `rawscope-render` - eventual consumer in T011.

#### Implementation Details

Add:

```rust
#[derive(Debug, Clone, PartialEq, Eq)]
pub struct DatasetEvidenceKey {
    pub column_name: String,
    pub column_index: usize,
}

#[derive(Debug, Clone, PartialEq, Eq)]
pub enum EvidenceKeyValidationError {
    MissingColumn { column_name: String, available_columns: Vec<String> },
    MissingValue { column_name: String, row_id: RowId },
    DuplicateValue { column_name: String, value: String, first: RowId, duplicate: RowId },
}
```

Required APIs:

```rust
pub fn validate_evidence_key(
    source: &LoadedSourceTable,
    column_name: &str,
) -> Result<DatasetEvidenceKey, EvidenceKeyValidationError>;

impl DatasetEvidenceKey {
    pub fn value<'a>(&self, row: &'a LoadedSourceRow) -> Option<&'a str>;
}
```

Trim only to decide whether a value is blank and to compare uniqueness. Return
the original stored string from `value()` so evidence does not silently rewrite
keys. Use a local `HashMap<String, RowId>` during validation; its lifetime ends
after validation. This is one optional O(n) startup scan and must not be stored
as a second full key index unless a future exact-row lookup requirement proves
that necessary.

Do not add key state to `LoadedSourceTable`. The validated descriptor belongs to
the session/app context because direct CLI loads may have no declared key.

#### Before / After

**Before:** internal row IDs are reproducible only for the exact loaded ordering.

**After:** callers may name a natural source key and RawScope can disclose it in
evidence while its internal dense ordinal contract remains intact.

#### Migration Notes

- No loader signature changes and no scan for existing direct CLI workflows.
- No evidence output changes until T011.

#### Misinterpretations To Prevent

- Wrong: assign `RowId` from the source key. Correct: `RowId` stays dense.
- Wrong: silently accept duplicates. Correct: a declared evidence key is unique.
- Wrong: normalize key text in evidence. Correct: preserve original value.
- Wrong: build an always-resident hash index. Correct: validate once only.

#### Invariants

- Every validated key has one non-blank unique value per loaded source row.
- `column_index` is valid for the same source table used during validation.
- Filter masks, points, GPU buffers, and source-row lookup remain ordinal.

#### Acceptance Criteria

- [x] Missing columns report deterministic available-column context.
- [x] Blank and duplicate values identify the offending row IDs.
- [x] String and numeric-looking keys retain their exact source text.
- [x] Existing local loading/filter tests remain unchanged and pass.
