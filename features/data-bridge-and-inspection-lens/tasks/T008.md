### T008 - Add GPU Inspection Focus Lens

#### Objective

Replace the flat transient probe rectangle with a dedicated WGPU inspection
focus treatment that precisely marks the exact bin, provides bounded nearby
context, and remains legible across RawScope's density modes.

#### Scope

- Split inspection rendering out of `ScatterBrushOverlayRenderer`.
- Add `ScatterInspectionOverlayRenderer` and dedicated WGSL.
- Render an exact-cell border/corner treatment, one-bin-radius soft halo, and
  low-opacity horizontal/vertical crosshair clipped to the plot.
- Support transient hover and persistent pin visual variants.
- Drive all pointer changes through one constant-size uniform write.
- Preserve the brush overlay and its amber semantics unchanged.
- Keep the overlay aligned with plot geometry, grid orientation, axes, pan,
  zoom, and high-DPI scaling.

#### Out Of Scope

- No density recoloring, bloom post-process, blur texture, compute pass, GPU
  readback, point selection, tooltip animation, perpetual pulse, or 3D camera.
- No axis text badges; T009 may add egui range cues near the tooltip.
- No evidence changes.

#### Blocked By

T006.

#### Implementation Details

Add:

```rust
#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub enum InspectionFocusKind { Hover, Pinned }

#[derive(Debug, Clone, Copy, PartialEq)]
pub struct ScatterInspectionOverlay {
    pub exact_rect: BrushScreenRect,
    pub neighborhood_rect: BrushScreenRect,
    pub focus_kind: InspectionFocusKind,
    pub presentation_alpha: f32,
}
```

`presentation_alpha` is clamped to `0..=1`; T008 uses `1.0` statically and T009
later drives bounded transition alpha. Uniforms contain exact/neighborhood rects,
plot/surface dimensions, border widths, alpha, and kind id. Keep `#[repr(C)]`
plus `Pod/Zeroable` and explicit padding.

Shader treatment:

- exact bin: crisp 1.5 px teal border plus short 5 px corner accents;
- neighborhood: analytic edge falloff inside the 3x3 rectangle, maximum alpha
  no greater than 0.10 so density remains readable;
- crosshair: 1 physical px through exact-bin center at low alpha, interrupted
  inside the exact cell so the border remains clear;
- hover: teal accent; pinned: amber/teal dual treatment consistent with existing
  selection/pin language;
- transparent elsewhere and clipped by viewport/scissor.

Use analytic distance in the fragment shader; do not allocate an intermediate
texture or sampler. Blend after density/points and before egui. If hover and pin
coexist, render pinned first and hover second with separate existing uniform
buffers/bind groups or two constant draws; do not rebuild pipelines.

Extract projection into a pure function that expands one bin at most one bin in
each direction and clips at grid boundaries. Test top-left and bottom-right y
orientation explicitly.

#### Before / After

**Before:** a thin rectangle follows hover and vanishes after the pointer leaves.

**After:** the GPU marks the exact analytical cell and nearby context with a
stable crosshair/halo, and pinning can remain visible independently.

#### Migration Notes

- Remove `render_probe` and probe buffers from `ScatterBrushOverlayRenderer` in
  the same task; update every call.
- Brush appearance and API remain otherwise compatible.

#### Misinterpretations To Prevent

- Wrong: blur or brighten density itself. Correct: composite a separate overlay.
- Wrong: animate forever. Correct: static after a short T009 transition.
- Wrong: neighborhood means selected rows. Correct: context halo only.
- Wrong: use logical egui pixels in WGSL. Correct: physical plot pixels.
- Wrong: retain probe code in brush renderer too. Correct: one new owner.

#### Invariants

- Exact overlay rect matches the same bin used by summary/pin.
- Focus does not change counts, colors, filters, point reveal, or evidence.
- Pointer updates write constant bytes and encode at most two small draws.
- No new resources are created per hover or frame.

#### Acceptance Criteria

- [ ] Brush renderer no longer owns inspection probe resources.
- [ ] Hover/pin variants pack deterministic uniforms and clip correctly.
- [ ] Neighborhood clips correctly at all grid edges.
- [ ] Crosshair/exact cell align after pan, zoom, resize, and DPI change.
- [ ] Cells, Topographic, Relief, and Difference remain readable underneath.
- [ ] Settled focus requests no perpetual redraw.
