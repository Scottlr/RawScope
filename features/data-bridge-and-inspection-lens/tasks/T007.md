### T007 - Add Difference Inspection Explanations

#### Objective

Explain a difference-density cell in the same signed terms as the shader:
active cohort share minus full-baseline share, including a truthful strength
rank among meaningful difference cells.

#### Scope

- Add a render-owned difference inspection summary built from active/baseline
  settled grids and their cohort totals.
- Report counts, shares, percentage-point delta, direction, and tie-inclusive
  absolute-delta percentile.
- Build the difference distribution once per settled active/baseline cache pair.
- Make zero-active and zero-baseline edge handling explicit.
- Project the summary into workbench inspection state.

#### Out Of Scope

- No change to difference formula, normalization, palette, shader, or mode
  eligibility.
- No relative-risk ratio, statistical significance, confidence interval,
  causal language, or category explanation.
- No tooltip layout/animation; T009 owns it.

#### Implementation Details

Add:

```rust
#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub enum DifferenceDirection { MoreCommonInActive, LessCommonInActive, Unchanged }

#[derive(Debug, Clone, Copy, PartialEq)]
pub struct DifferenceInspectionSummary {
    pub baseline_count: u32,
    pub active_count: u32,
    pub baseline_share: f64,
    pub active_share: f64,
    pub share_delta: f64,
    pub direction: DifferenceDirection,
    pub absolute_delta_percentile: Option<f64>,
}
```

Use the existing `difference_inspection` function as the single formula source.
Build a compact histogram of finite `abs(delta)` values for bins where either
count is nonzero. The percentile is the share of meaningful cells with absolute
delta less than or equal to the current absolute delta. If delta is exactly zero
or no meaningful cells exist, return `None`.

Use a small epsilon only if the existing fixed-point/render contract already
defines one; otherwise compare the exact computed f64 value and avoid inventing
a new semantic threshold. Direction is based on delta sign.

The app builds this distribution when both active and baseline inspection grids
are rebuilt. Hover may inspect a baseline-only cell in difference mode even when
active count is zero. Absolute-density mode still suppresses empty active cells
at the later UI layer.

#### Before / After

**Before:** tooltip emits raw active/baseline lines and a numeric delta.

**After:** it can say "Less common in active: 0.04% vs 0.19% baseline,
-0.15 percentage points; 91st percentile difference strength."

#### Migration Notes

- Keep `DifferenceInspection` and `difference_inspection` public APIs unchanged.
- New summary/distribution APIs are additive.

#### Misinterpretations To Prevent

- Wrong: compare raw counts. Correct: compare normalized cohort shares.
- Wrong: percentile means confidence. Correct: descriptive cell-strength rank.
- Wrong: positive means blue/negative means red without checking. Correct: sign
  labels derive from formula and must be reviewed against the actual shader.
- Wrong: divide by baseline to state percent change. Correct: percentage points.

#### Invariants

- Summary delta exactly matches existing CPU formula for the same cell.
- Baseline is always the full dataset in this bundle.
- A baseline-only region remains inspectable in difference mode.
- Hover does not rebuild or sort the difference distribution.

#### Acceptance Criteria

- [ ] Direction and percentage-point labels match delta sign.
- [ ] Unequal cohort sizes produce normalized shares.
- [ ] Absolute-delta percentile is deterministic and tie-inclusive.
- [ ] Baseline-only and active-only cells are represented correctly.
- [ ] Existing difference rendering/math tests stay unchanged and pass.
