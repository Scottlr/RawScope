### T001 - Add Versioned Local Session Manifest Contract

#### Objective

Create a small Rust interoperability boundary that can load a versioned local
RawScope session manifest, validate its startup intent, and resolve its dataset
path without depending on workbench or rendering code.

#### Scope

- Add `crates/rawscope-session` as a workspace member.
- Parse and serialize session schema v1 through serde/serde_json.
- Support local CSV/Parquet datasets and scatter/timeline field bindings.
- Carry optional display name, positive row limit, profile id, and evidence-key
  column.
- Resolve relative dataset paths from the manifest parent directory.
- Reject wrong artifact kinds, unsupported schema versions, URI sources,
  missing files, directories, format/extension mismatches, incomplete bindings,
  and unknown fields.
- Expose both the decoded DTO and a validated resolved session contract.

#### Out Of Scope

- No workbench CLI integration; T003 owns it.
- No source-table evidence-key scan; T002 owns it.
- No filters, comparison input, panel layout, visual styling, projection mode,
  animation state, evidence export, network source, or live session persistence.
- No Python package; T004/T005 own it.
- No JSON schema generator, package publication, installer, REST, or IPC.

#### Blocked By

None.

#### Why It Is Blocked

This is the bridge foundation and has no feature blocker. Its types must settle
before Rust startup and Python writing are implemented independently.

#### Implementation Details

The crate depends on `rawscope-data`, `serde`, and `serde_json`; it has no WGPU,
egui, winit, tracing, Arrow, or Parquet dependency of its own.

Public constants and DTOs:

```rust
pub const RAWSCOPE_SESSION_ARTIFACT_KIND: &str = "rawscope.session";
pub const RAWSCOPE_SESSION_SCHEMA_VERSION: u32 = 1;

#[derive(Debug, Clone, PartialEq, Eq, Serialize, Deserialize)]
#[serde(deny_unknown_fields)]
pub struct RawScopeSessionManifestV1 {
    pub artifact_kind: String,
    pub schema_version: u32,
    pub dataset: SessionDatasetV1,
    pub view: SessionViewV1,
}

#[derive(Debug, Clone, PartialEq, Eq, Serialize, Deserialize)]
#[serde(deny_unknown_fields)]
pub struct SessionDatasetV1 {
    pub path: PathBuf,
    pub format: SessionDataFormat,
    #[serde(default, skip_serializing_if = "Option::is_none")]
    pub display_name: Option<String>,
    #[serde(default, skip_serializing_if = "Option::is_none")]
    pub limit: Option<usize>,
    #[serde(default, skip_serializing_if = "Option::is_none")]
    pub evidence_key: Option<String>,
}

#[derive(Debug, Clone, Copy, PartialEq, Eq, Serialize, Deserialize)]
#[serde(rename_all = "snake_case")]
pub enum SessionDataFormat { Csv, Parquet }

#[derive(Debug, Clone, PartialEq, Eq, Serialize, Deserialize)]
#[serde(tag = "kind", rename_all = "snake_case", deny_unknown_fields)]
pub enum SessionViewV1 {
    Scatter { x: String, y: String, #[serde(default)] profile: Option<String> },
    Timeline { time: String, lane: String, #[serde(default)] profile: Option<String> },
}
```

Use owned strings in the decoded format. `ResolvedRawScopeSession` converts the
optional profile string with `parse_dataset_profile_id` and stores a
`DatasetProfileId`. It stores an absolute normalized `dataset_path`, the
absolute manifest path, the optional non-blank display name/evidence key,
format, positive limit, and a resolved scatter/timeline enum.

Required APIs:

```rust
pub fn load_session_manifest(
    manifest_path: impl AsRef<Path>,
) -> Result<ResolvedRawScopeSession, SessionManifestError>;

pub fn parse_session_manifest(
    json: &str,
) -> Result<RawScopeSessionManifestV1, SessionManifestError>;

pub fn session_manifest_json(
    manifest: &RawScopeSessionManifestV1,
) -> Result<String, SessionManifestError>;
```

Validation order must produce stable actionable errors: JSON syntax/unknown
field, artifact kind, schema version, dataset metadata, view binding/profile,
then filesystem resolution. `limit == 0`, blank field/key/name values, equal
scatter x/y, equal timeline time/lane, and unsupported profiles are invalid.

Paths containing a URI scheme marker such as `://` are rejected. Relative paths
join the manifest parent. `std::fs::canonicalize` is permitted only after the
path is known to exist; preserve the original manifest path in error context.
The declared format must agree case-insensitively with `.csv` or `.parquet`.

The canonical JSON shape is:

```json
{
  "artifact_kind": "rawscope.session",
  "schema_version": 1,
  "dataset": {
    "path": "data.parquet",
    "format": "parquet",
    "display_name": "Matchmaking games",
    "evidence_key": "game_id"
  },
  "view": {
    "kind": "scatter",
    "x": "white_rating",
    "y": "black_rating",
    "profile": "lichess-games"
  }
}
```

#### Before / After

**Before:** another process must reconstruct a changing list of CLI flags.

**After:** any local tool can write one stable manifest referencing CSV/Parquet,
and Rust can resolve it into validated startup intent.

#### Migration Notes

- This is additive and does not change direct CLI behavior or evidence schemas.
- The new crate is internal workspace API and must not be published in this task.
- Session schema v1 must be treated as stable once T004 writes it.

#### Misinterpretations To Prevent

- Wrong: put row data in JSON. Correct: JSON contains metadata only.
- Wrong: call this full workspace persistence. Correct: it is startup intent.
- Wrong: allow URLs for convenience. Correct: v1 is local paths only.
- Wrong: derive serde in `rawscope-data`. Correct: session serde stays here.
- Wrong: accept arbitrary view options. Correct: v1 binds one scatter/timeline.

#### Invariants

- A resolved session references one existing local regular file.
- Manifest-relative resolution is independent of current working directory.
- Decoded unknown fields fail rather than silently masking SDK spelling errors.
- The crate has no UI/GPU dependency and `rawscope-core` remains unchanged.
