#### Implementation Details

Required end-to-end product paths:

1. Existing CSV path -> Python `prepare` -> persistent session -> native scatter.
2. pandas/Polars/PyArrow table -> Parquet bundle -> native scatter.
3. Session timeline binding -> existing native timeline loader/render path.
4. Inspect occupied absolute cell -> exact tooltip -> focus -> pin -> v5 export.
5. Apply a real Lichess filter -> difference mode -> inspect positive and
   negative cells -> direction/share/delta agree with legend and evidence.
6. Toggle reduced motion -> tooltip/focus changes immediately with no animation
   frame loop.
7. Move within a cell and then stop -> no rebin/readback/source scan and no
   continuous redraw after 110 ms settles.
8. Pan/zoom/filter/project -> stale tooltip/pin invalidates according to policy.

Use the existing 200,000-row Lichess dataset for fast iterative review and the
343 MB dataset for large-path acceptance. Do not state row count or timing for
the latter unless measured through the benchmark protocol.

For performance verification, inspect code paths and existing counters/tests:
pointer movement may update current hit, immutable summary reference, one
constant-size overlay uniform, and finite presentation state only. It may not
call `build_scatter_inspection_grid`, `load_*`, density compute/readback,
`build_visual_field_catalog`, or source-row scans. Add a focused behavior test
around dispatch/readback/cache-rebuild counters only if an existing testable
counter/owner already exists; do not invent a diagnostic subsystem.

README examples must be short and executable:

Also document `RAWSCOPE_WORKBENCH`/PATH resolution, local-only behavior,
