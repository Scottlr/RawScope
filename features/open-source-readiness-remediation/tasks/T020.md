#### Implementation Details

The new wire contracts include explicit portable provenance:

```rust
pub struct EvidenceProvenanceV1 {
    pub source_label: String,
    pub fingerprint: ContentFingerprintV1, // { algorithm, value }
    pub display_path: Option<BundleRelativeOrPortablePath>,
    pub absolute_path_sensitive: Option<String>,
}

pub struct QuantizationDisclosureV1 {
    pub source_numeric_type: SourceNumericType,
    pub source_domain: NumericDomainV1,
    pub gpu_domain: NumericDomainV1,
    pub encoding: GpuNumericEncoding,
    pub maximum_absolute_error: Option<f64>,
}
```

`absolute_path_sensitive` is emitted only under an explicit sensitive-provenance
policy. Default artifacts carry a portable label and documented fingerprint.
Fingerprint metadata names the algorithm and coverage; it is never described as
full-source identity unless that exact content was hashed.

Exact integers remain JSON integers and exact decimal text. Exact f64 values use
round-trippable representation. Rounded analytical presentation values carry a
precision/unit label and never replace exact source fields. Quantization records
source type/domain, GPU encoding/domain, and the defined error/precision bound.

Contextual Markdown APIs separately handle table cells, inline code, list text,
headings, and link labels/destinations. Typed section writers receive artifact
metadata; version headings are never changed with string replacement.

#### Before / After

Before: legacy-only schemas leak paths, under-document precision, permit unsafe
Markdown contexts, and copy sections between versions.

After: v6/v4 are explicit safe portable contracts while every legacy schema
remains readable and accurately documented.

#### Migration Notes

- Legacy adapters stay available and byte-stable for safe inputs.
- Security-required hostile-input Markdown changes are captured as intentional
  compatibility exceptions with exact before/after and semantic reader tests.
- Do not silently promote a legacy artifact to v6/v4 during read.

#### Misinterpretations To Prevent

- Wrong: call the next scatter version v5.1. Correct: the wire constant is v6.
- Wrong: reuse timeline v3 for new fields. Correct: the wire constant is v4.
- Wrong: round JSON to match Markdown. Correct: preserve machine truth and label
  presentation rounding.
- Wrong: include an absolute path because it is useful. Correct: require explicit
  sensitive opt-in.

#### Invariants

- New scatter artifacts identify schema version 6; new timeline artifacts identify
  schema version 4.
- Untrusted text cannot escape its Markdown context.
- Default provenance contains no absolute local path.
- Numeric and quantization semantics have one typed source across formats.
- Legacy readers/writers remain explicit and supported.
