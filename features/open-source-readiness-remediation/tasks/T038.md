#### Implementation Details

Use an immutable checked value:

```rust
pub struct SelectionSnapshot {
    dataset_revision: DatasetRevision,
    filter_revision: FilterRevision,
    view_id: ViewId,
    selection_id: SelectionId,
    sorted_row_ids: Arc<[RowId]>,
    selected_bins: Arc<[u32]>,
    selected_count: u64,
    samples: Arc<[SelectionSample]>,
}
```

Construction validates revision/mask/row alignment and performs one pass over
current retained records/mask/geometry. IDs are strictly sorted/unique; samples
are deterministic/bounded. Complete membership or exact geometry establishes bin
coverage. Consumers borrow/clone the `Arc`, never rescan with different inputs.

#### Before / After

Before: filtered scatter evidence is disabled, linked rows ignore the filter,
selected bins can disappear without samples, and finalization rescans repeatedly.

After: all current selection/evidence consumers agree on one filtered row set.
