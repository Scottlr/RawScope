### T045 — Unify Source Adapter Normalization And Metadata

#### Objective

Make corrected CSV and Parquet adapters emit identical lane normalization,
source-aware dataset identity, and structured format logging over the checked
store while preserving each format's raw source representation.

#### Scope

- Primary audit findings: RS-035, RS-045, and RS-046.
- Define one validated lane-label normalization policy used by both adapters and
  retain raw labels separately.
- Replace synthetic-only metadata for all local loads with typed local source/
  format identity and portable display label.
- Replace format-specific/mislabelled log strings with structured
  `source_format`, dataset generation, path display, and row/chunk fields.
- Make legacy synthetic-only evidence unavailable for local data when it cannot
  represent provenance truthfully.
- Provide one adapter parity fixture/table consumed by CSV/Parquet tests.

#### Out of Scope

- Do not re-fix Parquet type dispatch/errors; T008 owns them.
- Do not stream ingestion/profile indexes; T009 owns it.
- Do not add new evidence wire fields; T020 owns v6/v4.
- Do not normalize away raw source label spelling.

#### Blocked By

T006, T007, T008, T044.

#### Why It Is Blocked

Both corrected adapters and raw/typed store semantics must exist before shared
normalization/metadata can replace format-specific behavior.

#### Related Code

- `local_dataset/{csv,parquet}.rs`, `dataset.rs`, store schema/source values.
- Workbench local scatter/timeline load logs and legacy evidence routing.
- Cross-format profile/import tests.

#### Implementation Touchpoints

- Read first: every lane label trim/parse, dataset identity constructor, format log,
  and local-to-synthetic evidence path.
- Edit first: data-owned lane/source format contracts, adapters, then workbench logs
  and legacy capability check.
- Symbols to search: lane dictionaries, `SyntheticDatasetMetadata`, hard-coded
  `CSV` log messages, `DatasetSource`, `path.display`, and evidence builder choice.
- Required structural changes: focused `lane_label.rs` only if no existing data
  owner fits; constants/policy stay near source domain.
- Do not edit: GPU/render interaction, report IO, Python bridge beyond shared
  fixture consumption in T012.
- Verify in order: adapter parity/metadata tests, workbench log/event projection
  tests, data/workbench tests, format, workspace check.
- Stop and ask: exact whitespace/case normalization and whether local legacy
  evidence must be emitted despite truthful-schema limitations.

#### Implementation Details

Use:

```rust
pub struct NormalizedLaneLabel(Arc<str>);
pub enum DatasetSourceFormat { Csv, Parquet }
```

Normalization validates decoded raw cell, applies one documented whitespace/empty/
case policy, and returns a stable label/ID; the store retains raw `SourceValue`.
Both adapters use the same function before lane dictionary assignment.

Local identity contains source format and portable display label/fingerprint hook,
not synthetic metadata. Logs use `tracing` fields and format-neutral messages; no
full payload or secret path. Legacy evidence capability returns typed
`IncompatibleSource` rather than constructing a false synthetic record.

#### Before / After

Before: lane meaning depends on file format, local data can claim synthetic
provenance, and Parquet logs as CSV.

After: adapter semantics/metadata/logs agree while raw spelling remains available.

#### Misinterpretations To Prevent

- Wrong: normalize by overwriting raw label. Correct: store both.
- Wrong: change log text only. Correct: source format is typed identity used by
  logs/errors/evidence capability.
- Wrong: force local data into legacy synthetic schema. Correct: fail explicitly.

#### Invariants

- Equal decoded lane values normalize identically across formats.
- Raw label and normalized ID remain distinguishable.
- Local source identity is never synthetic.
- Structured logs identify actual format and generation without payload leakage.

#### Acceptance Criteria

- [ ] Shared lane policy and cross-format fixtures pass.

- [ ] No Parquet success/error path logs as CSV.
- [ ] Synthetic-only legacy evidence rejects local inputs truthfully.
- [ ] Focused data/workbench tests and workspace check pass.
