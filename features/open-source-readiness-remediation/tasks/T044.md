### T044 — Preserve CSV Raw Values In DatasetStore

#### Objective

Complete CSV source-truth retention after immediate parser fixes by storing the
decoded raw cell separately from normalized valid/missing/invalid analytical state
in the checked `DatasetStore`.

#### Scope

- Primary audit finding: RS-030.
- Adapt corrected CSV decoding to T006 store chunks/cells.
- Preserve post-CSV-decoding, pre-trim/parse text for retained evidence columns.
- Store normalized typed value and missing/invalid classification separately.
- Require evidence-key/bound/source-sample columns in the retained-source policy
  or fail admission explicitly under budget.
- Remove any path that reconstructs source evidence from normalized values.

#### Out of Scope

- Do not change CSV limits/inference; T007 already fixed them.
- Do not unify Parquet/lane/source metadata; T045 owns cross-adapter parity.
- Do not stream chunks/profile indexes; T009 owns it.
- Do not retain every unselected source column without budget policy.

#### Blocked By

T006, T007.

#### Why It Is Blocked

The corrected parser and typed raw/normalized store contracts must exist before
retention can be implemented without duplicate mutable tables.

#### Related Code

- `local_dataset/csv.rs`, store cell/chunk/retention policy, source-row lookup.
- Evidence-key validation and workbench source drilldown.
- CSV import/evidence tests.

#### Implementation Touchpoints

- Read first: exact CSV crate decoding behavior, trim/null/parse rules, all evidence
  source reconstruction, and retention budgets.
- Edit first: CSV-to-store cell conversion and retained-column policy, then remove
  normalized-to-source reconstruction.
- Symbols to search: `.trim`, parsed value formatting, source row strings, empty
  string/null handling, and duplicate `Vec<String>`.
- Required structural changes: `RetainedCsvCell`/store-owned source lexeme contract
  if `SourceValue::Utf8` cannot distinguish decoded spelling cleanly.
- Do not edit: Parquet, analysis, evidence schemas, GPU, or UI.
- Verify in order: raw/normalized fixture tests, key/drilldown tests, data tests,
  format, workspace check.
- Stop and ask: which columns must always be retained and what happens when their
  exact raw bytes exceed budget.

#### Implementation Details

For each retained CSV field, pass both:

```rust
pub struct DecodedCsvCell {
    raw: Arc<str>,
    analytical: CellState<SourceValue>,
}
```

The store may intern/share raw values but may not normalize them in place. Invalid
numeric text remains raw plus `InvalidCell` reason; missing policy remains distinct.
Unretained columns return `CellRef::NotRetained(reason)`, never a formatted typed
value. Budget admission occurs before chunk commit.

#### Before / After

Before: evidence can silently show trimmed/reformatted values that differ from CSV.

After: exact decoded spelling and analytical normalization coexist under one
generation/retention policy.

#### Migration Notes

- Keep current CSV dialect/encoding behavior documented; “raw” means decoded cell,
  not original byte slice including CSV quoting.
- T009 streams the same dual cell contract.

#### Misinterpretations To Prevent

- Wrong: store only raw strings and reparse everywhere. Correct: retain separate
  typed analytical state.
- Wrong: format numeric typed value for evidence. Correct: use retained raw cell.
- Wrong: silently omit over-budget required evidence columns. Correct: fail/degrade
  only by explicit policy.

#### Invariants

- Normalization never mutates retained raw text.
- Missing/invalid/valid remain distinct.
- Required evidence columns are retained or admission fails explicitly.
- Store chunk commit remains rectangular/atomic.

#### Acceptance Criteria

- [ ] CSV store cells expose raw and analytical values separately.
- [ ] Whitespace/large integer/null-like/invalid fixtures preserve decoded spelling.
- [ ] Drilldown/evidence uses raw values, analysis uses typed state.
- [ ] Not-retained/budget outcomes are explicit.
- [ ] Focused data tests and workspace check pass.

#### Testing Guidance

- Use a small deterministic CSV with quoting, whitespace, empty/null-like, invalid,
  and large unsigned values.
- Assert source/evidence and analytical results separately.
- No large-file or timing tests.

#### Agent Handoff Context

T045 aligns Parquet/source metadata; T009 makes this chunked; T020 serializes
portable source truth.

## Final Notes

- Recommended order: dual cell, retention policy, evidence consumers, remove
  reconstruction.
- Human review: required retained columns/default byte budget.
- Risk: retaining both raw and typed data increases RAM; T028/T057 account it.
