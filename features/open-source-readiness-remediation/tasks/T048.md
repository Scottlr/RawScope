### T048 — Migrate Evidence Callers And Remove Render Ownership

#### Objective

Switch workbench/report/tests to `rawscope-evidence`, remove temporary render
evidence modules/re-exports, and leave render with presentation/GPU concerns only.

#### Scope

- Primary audit finding: RS-136 (evidence/render boundary portion).
- Change workbench export/report imports/builders to evidence canonical/v1-v6 and
  timeline v1-v4 APIs.
- Move remaining evidence tests/fixtures to the evidence crate or workbench
  integration owner.
- Delete render evidence models/export modules and temporary compatibility
  re-exports after every caller migrates.
- Remove Serde/Serde JSON from `rawscope-render` if no render-owned use remains and
  update manifests/path+version dependencies.
- Keep render-only visual context types mapped explicitly into evidence context.

#### Out of Scope

- Do not add background export; T049 owns controller/jobs.
- Do not change artifact bytes/validation/formatting/bundle schema.
- Do not move analysis/render algorithms or reorganize all render modules.
- Do not remove supported legacy adapters.

#### Blocked By

T020, T021, T046, T047.

#### Why It Is Blocked

Both legacy families, new safe versions, and bundle APIs must exist before callers
can move and the old owner can be deleted in one compiling PR.

#### Related Code

- Render facade and every evidence/export/model module.
- Workbench `app_export*`, `app_report_bundle*`, selection evidence construction.
- Render/evidence/workbench manifests and tests/benches.

#### Implementation Touchpoints

- Read first: `rg` every old render evidence symbol/import/re-export and Serde use.
- Edit first: workbench/evidence imports/builders, integration tests/bench, then
  render deletions/facade/manifest.
- Symbols to search: all evidence type/function/schema constants from render,
  `serde`, `serde_json`, and temporary/deprecated re-exports.
- Required structural changes: explicit evidence-context adapter at workbench/
  render boundary; no compatibility module left in render.
- Do not edit: job system, UI layout, shaders, data ingestion.
- Verify in order: evidence tests, workbench report/export tests/bench compile,
  render tests, cargo tree/metadata, format, workspace check.
- Stop and ask: if an external pre-release consumer requires a temporary render
  re-export beyond this task; document an explicit removal version instead of
  leaving dual ownership silently.

#### Implementation Details

Migrate one caller family at a time while compiling: builders from T038/T016,
scatter export, timeline export, report bundles, tests, bench. Render visual config
is converted by a small workbench/evidence adapter; evidence never depends on
render/WGPU.

After the last import moves, delete semantic files and facade exports. Verify final
Cargo DAG and remove unused Serde dependencies. No shim may contain copied logic.

#### Before / After

Before: evidence implementation remains duplicated/visible under render despite a
new crate.

After: evidence is the sole semantic/wire/bundle owner and render is presentation-
only at this boundary.

#### Migration Notes

- This task may break pre-release Rust import paths intentionally; artifact bytes
  remain compatible.
- T034 removes any other residual boundary debt later.

#### Misinterpretations To Prevent

- Wrong: keep render wrappers indefinitely. Correct: migrate all workspace callers
  and delete the old public path before publication.
- Wrong: make evidence depend on render types. Correct: map typed visual context at
  composition boundary.
- Wrong: move files without manifest cleanup. Correct: remove obsolete deps.

#### Invariants

- One crate owns evidence semantics/serialization/bundles.
- Evidence has no render/GPU/UI dependency.
- Render has no evidence DTO/Serde use after cleanup.
- Artifact behavior remains unchanged.

- [ ] Workbench mapping is explicit and typed.

- [ ] Cargo DAG matches intended boundary.
