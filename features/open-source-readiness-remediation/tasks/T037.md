### T037 — Repair Current Timeline Lane And Range Semantics

#### Objective

Correct timeline lane orientation, timestamp/lane overflow, empty-config bypass,
and before/after error classification in the existing CPU/GPU/render/interaction
owners before resident-resource migration.

#### Scope

- Primary audit findings: RS-053 through RS-057.
- Define lane 0 as the top screen lane, matching current brush/axis semantics, and
  apply it consistently in compute, render sampling, overlays, labels, and tests.
- Replace lossy/overflowing timestamp and lane bin arithmetic with one documented
  current CPU/WGSL formula and parity vectors.
- Classify before/after-range events before converting offsets.
- Validate all non-zero/domain/device-independent config before empty-input return.
- Return typed errors rather than panics or misleading range failures.

#### Out of Scope

- Do not make resources resident or nonblocking; T024 owns lifecycle.
- Do not add gesture scheduling/reprojection; T042 owns containment.
- Do not move math into analysis; T013 later adopts the corrected vectors.
- Do not reverse existing brush/axis semantics to match the broken shader.

#### Blocked By

None.

#### Why It Is Blocked

The defects are confirmed current behavior and can be fixed with existing types/
tests before foundational migrations.

#### Related Code

- `gpu_timeline_density.rs`, `gpu_timeline_density_pack.rs`, and timeline WGSL.
- `timeline_density_renderer.rs`, `timeline_brush.rs`, `timeline_viewport.rs`, and
  current axis lane labels.
- CPU timeline density/reference/summary paths and ignored GPU timeline tests.

#### Implementation Touchpoints

- Read first: every screen-y/lane and time/bin conversion plus current error/empty
  fast paths.
- Edit first: shared private mapping functions/vectors in current render owner,
  compute/render shaders, then brush/axis parity tests.
- Symbols to search: `uv.y`, lane fraction, timestamp subtraction/multiplication,
  casts, empty input return, and range error variants.
- Required structural changes: one named lane convention and one table of boundary
  vectors consumed by CPU/adapter tests; no macro/codegen.
- Do not edit: workbench scheduler, resource ownership, evidence, or data loading.
- Verify in order: pure mapping/error tests, brush/axis tests, ignored GPU first/
  last-lane parity when adapter exists, format, workspace check.
- Stop and ask: if lane 0 is not intended at top or supported timestamp span must
  be reduced rather than implementing safe arithmetic.

#### Implementation Details

Document conversions explicitly:

```rust
pub enum TimelinePlacement {
    BeforeRange,
    InGrid { time_bin: u32, lane_bin: u32 },
    AfterRange,
}
```

Use u128/quotient-remainder CPU math and a proven u32-word WGSL decomposition for
`offset * grid / span`. Check lane/grid product before indexing. Screen fraction
0/top maps to lane 0; perform exactly one render-space y inversion where WGPU UV
orientation requires it.

`TimelineDensityComputeConfig::try_new` validates domain, lane count, grid, and
checked bin count. Entry points validate config first, then may return an empty
zero grid. Far-before/after values return sentinels/errors without attempting a
large offset conversion.

#### Before / After

Before: lanes render opposite interaction, large timestamps/lanes lose precision
or overflow, far-after events misreport, and empty data bypasses invalid config.

After: every timeline consumer shares one orientation and bounded placement/
error contract.

#### Migration Notes

- T013 takes ownership of normative CPU placement; T024 reuses the corrected
  shader/vectors in resident state.
- Preserve artifact/UI lane numbering; this fixes pixels, not analyst meaning.

#### Misinterpretations To Prevent

- Wrong: flip both compute row and render UV. Correct: define one mapping and use
  end-to-end first/last-lane tests to prevent a double flip.
- Wrong: cast span/offset to f32. Correct: use integer-safe semantics.
- Wrong: handle empty data before validation. Correct: validate first.

#### Invariants

- Lane 0 is top-screen across compute/presentation/interaction.
- CPU/WGSL placement agrees at every boundary vector.
- Index arithmetic is checked before buffer access.
- Empty input cannot bypass invalid configuration.
- Before/after classification is independent of offset narrowing.

#### Acceptance Criteria

- [ ] Far-before/far-after events return correct typed outcomes.

- [ ] Focused pure/adapter tests, format, and workspace check pass.
