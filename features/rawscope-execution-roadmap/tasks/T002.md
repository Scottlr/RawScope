### T002 - Add Dataset Identity And Field Bindings

#### Objective
Add a source-aware dataset identity model that describes synthetic and local CSV datasets without pretending local data is synthetic. This becomes the source of truth for evidence provenance and future UI labels.

#### Scope
- Extend `crates/rawscope-data/src/dataset.rs` with dataset identity, source kind, visual kind, and field binding types.
- Export the new types from `crates/rawscope-data/src/lib.rs`.
- Add identity fields to `SyntheticPointDataset`, `SyntheticEventDataset`, `LoadedScatterDataset`, and `LoadedTimelineDataset`.
- Populate identity in `generate_synthetic_points()`, `generate_synthetic_events()`, `load_scatter_dataset()`, and `load_timeline_dataset()`.
- Update workbench state to store `DatasetIdentity` instead of using only `SyntheticDatasetMetadata`.
- Add focused tests for synthetic identity and CSV identity.

#### Out of Scope
- Do not remove `SyntheticDatasetMetadata` yet.
- Do not change evidence JSON schemas in this task.
- Do not add serde derives to data types.
- Do not compute cryptographic fingerprints yet.
- Do not add Parquet/Arrow, egui, row table UI, or GPU row-id preservation.

#### Blocked By
T001

#### Why It Is Blocked
Documentation should first stop pointing future agents at old Milestone 1 work, so this foundational model change is implemented against the correct roadmap baseline.

#### Implementation Details
- In `crates/rawscope-data/src/dataset.rs`, keep `SyntheticDatasetMetadata` and add:
```rust
use std::path::PathBuf;

#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub enum VisualDatasetKind {
    Scatter,
    Timeline,
}

#[derive(Debug, Clone, PartialEq, Eq)]
pub enum DatasetSource {
    Synthetic {
        seed: u64,
        generator: &'static str,
    },
    LocalCsv {
        path: PathBuf,
        limit: Option<usize>,
    },
}

#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub enum DatasetFieldRole {
    X,
    Y,
    Time,
    Lane,
}

#[derive(Debug, Clone, PartialEq, Eq)]
pub struct DatasetFieldBinding {
    pub role: DatasetFieldRole,
    pub column_name: String,
}

#[derive(Debug, Clone, PartialEq, Eq)]
pub struct DatasetIdentity {
    pub visual_kind: VisualDatasetKind,
    pub source: DatasetSource,
    pub row_count: usize,
    pub field_bindings: Vec<DatasetFieldBinding>,
    pub lane_labels: Vec<String>,
}
```
- Add constructors:
```rust
impl DatasetIdentity {
    pub fn synthetic_scatter(seed: u64, row_count: usize) -> Self;
    pub fn synthetic_timeline(seed: u64, row_count: usize, lane_count: u32) -> Self;
    pub fn local_csv_scatter(
        path: PathBuf,
        row_count: usize,
        limit: Option<usize>,
        x_column: impl Into<String>,
        y_column: impl Into<String>,
    ) -> Self;
    pub fn local_csv_timeline(

        row_count: usize,
        limit: Option<usize>,
        time_column: impl Into<String>,
        lane_column: impl Into<String>,
        lane_labels: Vec<String>,
    ) -> Self;
}
```

#### Migration Notes
- Existing synthetic metadata remains available so evidence v1 does not break.
- The new identity is additive. Existing public constructors should still work.
- Workbench can store both identity and metadata temporarily.

#### Misinterpretations To Prevent
- Wrong interpretation: "Local CSV can keep using seed 0 as provenance."
  Correct rule: local CSV identity must be `DatasetSource::LocalCsv`.
- Wrong interpretation: "Add serde derives everywhere so exports are easy."
  Correct rule: keep data crate free from serde until a specific serialization need is accepted.
- Wrong interpretation: "Add file hashes now."
  Correct rule: leave fingerprints for a later evidence or ingestion task unless the user approves the algorithm and cost.

#### Invariants
- Synthetic and local sources must be distinguishable in data state.
- Field bindings must preserve the original user-selected column names.
- Timeline local identity must preserve deterministic lane labels.
- No new broad dependency is introduced.

#### Acceptance Criteria
- [ ] Synthetic point/event datasets expose `identity`.

- [ ] Local CSV identity includes path, limit, field bindings, visual kind, and row count.
- [ ] Workbench stores dataset identity without breaking current evidence v1 export.
- [ ] `cargo test -p rawscope-data` passes.
