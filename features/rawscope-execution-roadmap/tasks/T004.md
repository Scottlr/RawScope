### T004 - Retain Local Source Rows For Drilldown

#### Objective
Preserve original local CSV row values by `RowId` so future selected-row drilldown and evidence exports can show source rows, not only visual x/y or time/lane projections.

#### Scope
- Add local row-table storage types under `rawscope-data`.
- Populate source rows in `load_scatter_dataset()` and `load_timeline_dataset()`.
- Add source-row lookup helpers by `RowId`.
- Store source rows in `LoadedScatterDataset` and `LoadedTimelineDataset`.
- Add tests for deterministic row retention, row-id lookup, limit behavior, and missing/empty cell preservation.

#### Out of Scope
- Do not build a UI row table; that belongs to T006/T007.
- Do not include row values in evidence JSON yet; that belongs to T005.
- Do not build a dataframe/query API.
- Do not add Parquet/Arrow.
- Do not retain unbounded rows for every future source without a reviewable policy.

#### Blocked By
T002

#### Why It Is Blocked
Source row retention should attach to source-aware dataset identity and field bindings rather than adding another ad hoc local-data concept.

#### Implementation Details
- In `crates/rawscope-data/src/local_dataset.rs`, add:
```rust
use rawscope_core::RowId;

#[derive(Debug, Clone, PartialEq, Eq)]
pub struct LoadedSourceRow {
    pub row_id: RowId,
    pub values: Vec<String>,
}

#[derive(Debug, Clone, PartialEq, Eq)]
pub struct LoadedSourceTable {
    pub columns: Vec<LoadedColumnSchema>,
    pub rows: Vec<LoadedSourceRow>,
}

impl LoadedSourceTable {
    pub fn row(&self, row_id: RowId) -> Option<&LoadedSourceRow> {
        let index = usize::try_from(row_id.0).ok()?;
        self.rows.get(index).filter(|row| row.row_id == row_id)
    }

    pub fn column_names(&self) -> impl Iterator<Item = &str> {
        self.columns.iter().map(|column| column.name.as_str())
    }
}
```
- Add fields:

#### Migration Notes
- Loaded dataset construction becomes slightly larger but behavior remains additive.
- Source row retention follows the already-loaded CSV rows and `--limit`; it does not add a new background loader.
- Existing callers can ignore `source_rows` until T005/T006.

#### Misinterpretations To Prevent
- Wrong interpretation: "This is a dataframe API."
  Correct rule: source rows are retained for evidence/drilldown lookup only.
- Wrong interpretation: "Skip empty cells."
  Correct rule: preserve column alignment; empty cells remain empty strings.
- Wrong interpretation: "Use CSV physical line numbers as RowId."
  Correct rule: current `RowId(0)` maps to first loaded data row after headers, respecting `--limit`.

#### Invariants
- `source_rows.rows.len()` equals the loaded visual record count.
- `source_rows.row(RowId(n))` returns the row whose visual record has `row_id == RowId(n)`.
- Source-row lookup must use checked `usize::try_from(row_id.0)` conversion rather than unchecked casts.
- Source row values preserve column order.
- The retention policy must be documented as current in-memory CSV row retention, not the future columnar store.
