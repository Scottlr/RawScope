### T009 - Add Missingness Heatmap Slice

#### Objective
Add the first data-quality visual primitive: a missingness heatmap that shows null/empty-value shape across rows and columns, supports brushing, and can produce evidence hooks.

#### Scope
- Add CPU reference missingness aggregation for local CSV source rows.
- Add deterministic tests for missingness grids using CSV fixtures.
- Add a simple workbench view mode for missingness once UI and linked selection contracts exist.
- Add brushing or cell selection over column/range regions.
- Add evidence summary hooks for selected missingness regions.

#### Out of Scope
- Do not add GPU acceleration in the first missingness slice unless CPU reference is already stable.
- Do not add Parquet/Arrow.
- Do not add general data profiling, SQL, or dataframe operations.
- Do not add dashboards or arbitrary pivot tables.
- Do not make performance claims.

#### Implementation Details
- Add a render-owned reference module:
```rust
// crates/rawscope-render/src/missingness_reference.rs
use rawscope_core::RowId;
use rawscope_data::LoadedSourceTable;

#[derive(Debug, Clone, PartialEq, Eq)]
pub struct MissingnessGrid {
    pub row_bucket_count: u32,
    pub column_count: u32,
    pub cells: Vec<MissingnessCell>,
}

#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub struct MissingnessCell {
    pub row_bucket: u32,
    pub column_index: u32,
    pub missing_count: u32,
    pub total_count: u32,
}

pub fn missingness_grid(
    source_table: &LoadedSourceTable,
    row_bucket_count: u32,
) -> MissingnessGrid;
```
- Define missingness for the first slice as trimmed empty string. If this conflicts with desired null semantics, stop and ask.
- Add selection model:
```rust
#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub struct MissingnessSelection {

```

