### T011 - Add Chunked Parquet Ingestion

#### Objective
Add Parquet/Arrow-backed chunked local dataset loading after RawScope has stable source identity, source-row evidence, and UI/export flows.

#### Scope
- Replace the current explicit Parquet-deferred error with a narrow local Parquet ingestion path.
- Add chunked columnar dataset structures in `rawscope-data`.
- Support scatter bindings for numeric x/y columns and timeline bindings for timestamp/lane columns.
- Preserve stable `RowId` assignment across chunks.
- Preserve enough row/source evidence for drilldown and evidence v2.
- Add deterministic tests with small Parquet fixtures.

#### Out of Scope
- Do not add DataFusion or SQL.
- Do not add cloud object-store connectors.
- Do not add a general dataframe API.
- Do not optimize for all Parquet logical types in the first slice.
- Do not claim zero-copy.

#### Blocked By
T002, T003, T004, T005

#### Why It Is Blocked
Parquet should not arrive until RawScope knows how to describe dataset identity, generic visual records, source row evidence, and evidence schemas. Otherwise a large dependency lands before the product contract is stable.

- Add a module:

- Add chunk types:
```rust
#[derive(Debug, Clone, PartialEq, Eq)]
pub struct DatasetChunkId(pub u32);

#[derive(Debug, Clone, PartialEq)]
pub struct LoadedColumnarChunk {
    pub chunk_id: DatasetChunkId,
    pub row_id_start: RowId,
    pub row_count: usize,
}

#[derive(Debug, Clone, PartialEq)]
pub struct LoadedColumnarDataset {
    pub identity: DatasetIdentity,
    pub schema: Vec<LoadedColumnSchema>,
    pub chunks: Vec<LoadedColumnarChunk>,
}
```
- Add loader functions:
```rust
pub fn load_parquet_scatter_dataset(
    path: impl AsRef<Path>,
    x_column: &str,
    y_column: &str,
    limit: Option<usize>,
) -> Result<LoadedScatterDataset, DatasetLoadError>;

pub fn load_parquet_timeline_dataset(
    path: impl AsRef<Path>,
    time_column: &str,
    lane_column: &str,
    limit: Option<usize>,
) -> Result<LoadedTimelineDataset, DatasetLoadError>;
```
- Update local dispatch functions so `.csv` and `.parquet` share public entry points:
```rust
pub fn load_scatter_dataset(...) -> Result<LoadedScatterDataset, DatasetLoadError>;
pub fn load_timeline_dataset(...) -> Result<LoadedTimelineDataset, DatasetLoadError>;
```
- Add error variants:
```rust

```
- Row-id invariant:
```rust

```
where global offset respects `--limit` and chunk order.
- Update docs to remove "Parquet deferred" only after tests pass.

- Wrong interpretation: "Add DataFusion because Parquet is here."
  Correct rule: no DataFusion or SQL.
- Wrong interpretation: "Claim zero-copy Arrow path."
  Correct rule: use copy-minimising language only when technically accurate.
- Wrong interpretation: "Support every Parquet type."
  Correct rule: support the explicit scatter/timeline bindings needed by RawScope's current views.

#### Invariants
- Row ids remain stable and deterministic.
- Parquet import is local-first.
- Dataset identity records source and bindings.
- Evidence v2 and drilldown still work for selected rows.
- No performance claims until T012 benchmarks.
