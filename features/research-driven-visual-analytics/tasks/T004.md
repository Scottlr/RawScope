### T004 - Add Selection Baseline Comparison Summaries

#### Objective

Make every finalized selection explain itself against the dataset baseline. Add
code-owned selected-vs-baseline comparison summaries for scatter, timeline, and
missingness without creating a dashboard or query engine.

#### Scope

- Create `crates/rawscope-render/src/selection_comparison.rs`.
- Add comparison summary structs for scatter, timeline, and missingness.
- Build comparisons from existing selected-region summaries plus full active
  records/source rows.
- Include counts, percentages, selected share, baseline share, and delta fields
  that are deterministic and reviewable.
- Export comparison types from `rawscope-render`.

#### Out of Scope

- Do not add UI in this task; T005 owns the workbench panel.
- Do not add arbitrary filters, dashboard crossfilters, or SQL-like predicates.
- Do not add new dataset loading modes.
- Do not change evidence JSON schemas; T007 owns evidence v3.
- Do not add benchmark claims or performance gates.

#### Implementation Details

Create `crates/rawscope-render/src/selection_comparison.rs`:

```rust
//! Selected-vs-baseline comparison summaries for visual selections.

use rawscope_data::{ScatterPointRecord, TimelineEventRecord};

use crate::{
    MissingnessSelectionSummary, SelectedCategoryCounts, SelectedEventTypeCounts,
    SelectedRegionSummary, TimelineSelectionSummary,
};

#[derive(Debug, Clone, Copy, PartialEq)]
pub struct ComparisonRatio {
    pub selected_count: usize,
    pub baseline_count: usize,
    pub selected_percentage: f32,
    pub baseline_percentage: f32,
    pub delta_percentage_points: f32,
}

#[derive(Debug, Clone, PartialEq)]
pub struct ScatterSelectionComparison {
    pub selected_row_count: usize,
    pub baseline_row_count: usize,
    pub selected_percentage: f32,
    pub point_kind_ratios: ScatterKindComparison,
}

#[derive(Debug, Clone, Copy, PartialEq)]
pub struct ScatterKindComparison {
    pub cluster: ComparisonRatio,
    pub background: ComparisonRatio,
    pub outlier: ComparisonRatio,
    pub unclassified: ComparisonRatio,
}

#[derive(Debug, Clone, PartialEq)]
pub struct TimelineSelectionComparison {
    pub selected_event_count: usize,
    pub baseline_event_count: usize,
    pub selected_percentage: f32,
    pub event_kind_ratios: TimelineKindComparison,
    pub lane_ratios: Vec<ComparisonRatio>,
}

#[derive(Debug, Clone, Copy, PartialEq)]
pub struct TimelineKindComparison {
    pub background: ComparisonRatio,
    pub spike: ComparisonRatio,
    pub stale_lane: ComparisonRatio,
    pub high_value_band: ComparisonRatio,
    pub unclassified: ComparisonRatio,
}

#[derive(Debug, Clone, Copy, PartialEq)]
pub struct MissingnessSelectionComparison {
    pub selected_missing_count: u64,
    pub selected_total_count: u64,
    pub baseline_missing_count: u64,
    pub baseline_total_count: u64,
    pub selected_missing_ratio: f32,
    pub baseline_missing_ratio: f32,
    pub delta_percentage_points: f32,
}

pub fn scatter_selection_comparison(
    points: &[ScatterPointRecord],
    summary: SelectedRegionSummary,
) -> ScatterSelectionComparison;

pub fn timeline_selection_comparison(
    events: &[TimelineEventRecord],
    lane_count: u32,
    summary: &TimelineSelectionSummary,
) -> TimelineSelectionComparison;

pub fn missingness_selection_comparison(
    selected: &MissingnessSelectionSummary,
    baseline_missing_count: u64,
    baseline_total_count: u64,
) -> MissingnessSelectionComparison;
```

Baseline rules:

- Scatter baseline is the active point slice used by the current view.
- Timeline baseline is the active event slice used by the current view.
- Missingness baseline is the whole missingness grid/source table for the active
  local dataset.
- Percentages use `0.0` when denominators are zero.
- Delta is `selected_percentage - baseline_percentage`.

Export in `crates/rawscope-render/src/lib.rs`:

```rust
mod selection_comparison;

pub use selection_comparison::{
    missingness_selection_comparison, scatter_selection_comparison,
    timeline_selection_comparison, ComparisonRatio, MissingnessSelectionComparison,
    ScatterKindComparison, ScatterSelectionComparison, TimelineKindComparison,
    TimelineSelectionComparison,
};
```

Add integration tests in `crates/rawscope-render/tests/selection_comparison.rs`.
Do not place large table fixtures in production files.

#### Migration Notes

- Existing summaries continue to exist and remain the source input.
- Existing evidence/export code should compile unchanged.
- This task adds a new render-owned comparison layer; it does not replace
  `SelectedRegionSummary` or `TimelineSelectionSummary`.

#### Misinterpretations To Prevent

- Wrong interpretation: make a generic statistical comparison engine.
  Correct rule: implement only the fixed selected-vs-baseline fields listed in
  this task.
- Wrong interpretation: compare against arbitrary filters or SQL predicates.
  Correct rule: baseline is the active loaded records/source table.
- Wrong interpretation: add the workbench UI here.
  Correct rule: this task is render-owned summary logic only.
- Wrong interpretation: treat comparison ratios as benchmark metrics.
  Correct rule: ratios describe selected data composition only.

#### Invariants

- Comparisons are deterministic for the same input records and summary.
- Delta fields are selected percentage minus baseline percentage.
- Empty baseline denominators produce `0.0`, not NaN or panic.
- Scatter local rows count as `unclassified`.
- Timeline local rows count as `unclassified`.
- No external query or dataframe layer is introduced.
