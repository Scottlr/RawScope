### T001 - Add Density Encoding Contract And Controls

#### Objective

Make density color semantics an explicit code contract instead of an implicit
shader detail. Scatter and timeline views must carry transform, palette,
normalization scope, grid size, and count range into renderer config, UI state,
and report-export context.

#### Scope

- Create `crates/rawscope-render/src/density_encoding.rs`.
- Add render-owned density encoding types and pure intensity functions.
- Extend `ScatterDensityRendererConfig` and `TimelineDensityRendererConfig` with
  `encoding: DensityEncoding`.
- Extend the scatter/timeline WGSL render params with transform and palette ids.
- Update `apps/rawscope-workbench/src/ui_visual_encoding.rs` to consume
  render-owned encoding metadata instead of duplicating transform/palette names.
- Add workbench UI actions to select `Linear` or `Log1p` per active view.
- Keep existing log1p behavior as the default.

#### Out of Scope

- Do not add rank/equalized transform in this task. T006 adds aggregate metadata
  needed for that without faking it.
- Do not add new chart types.
- Do not add DataFusion, Tauri, web, cloud, plugins, or downloader behavior.
- Do not change GPU density compute; this task changes render color mapping and
  UI state only.
- Do not add benchmark claims or timing UI.

#### Blocked By

None

#### Why It Is Blocked

This is the foundation for later visual truthfulness, evidence, and comparison
tasks. It can start immediately because the current renderer already has
hard-coded log1p behavior and the uncommitted `ui_visual_encoding.rs` foothold
already displays it.

#### Implementation Details

Create `crates/rawscope-render/src/density_encoding.rs`:

```rust
//! Density color encoding contracts shared by renderers, UI, and evidence.

#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub enum DensityTransform {
    Linear,
    Log1p,
}

impl DensityTransform {
    pub fn shader_id(self) -> u32 {
        match self {
            Self::Linear => 0,
            Self::Log1p => 1,
        }
    }

    pub fn label(self) -> &'static str {
        match self {
            Self::Linear => "linear(count)",
            Self::Log1p => "log1p(count)",
        }
    }
}

#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub enum DensityPalette {
    ScatterSequential,
    TimelineSequential,
}

impl DensityPalette {
    pub fn shader_id(self) -> u32 {
        match self {
            Self::ScatterSequential => 0,
            Self::TimelineSequential => 1,
        }
    }
}

#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub enum DensityNormalization {
    ViewportMax,
}

impl DensityNormalization {
    pub fn label(self) -> &'static str {
        "viewport max"
    }
}

#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub struct DensityEncoding {
    pub transform: DensityTransform,
    pub palette: DensityPalette,
    pub normalization: DensityNormalization,
}

impl DensityEncoding {
    pub fn scatter_default() -> Self {
        Self {
            transform: DensityTransform::Log1p,
            palette: DensityPalette::ScatterSequential,
            normalization: DensityNormalization::ViewportMax,
        }
    }

    pub fn timeline_default() -> Self {
        Self {
            transform: DensityTransform::Log1p,
            palette: DensityPalette::TimelineSequential,
            normalization: DensityNormalization::ViewportMax,
        }
    }
}

pub fn density_intensity(count: u32, max_count: u32, transform: DensityTransform) -> f32 {
    if count == 0 || max_count == 0 {
        return 0.0;
    }

    match transform {
        DensityTransform::Linear => (count as f32 / max_count as f32).clamp(0.0, 1.0),
        DensityTransform::Log1p => {
            let count_scale = (count as f32 + 1.0).ln();
            let max_count_scale = (max_count as f32 + 1.0).ln();
            (count_scale / max_count_scale).clamp(0.0, 1.0)
        }
    }
}
```

In both WGSL files, replace hard-coded transform logic with ids:

```wgsl
fn density_intensity(count: u32, max_count: u32, transform_id: u32) -> f32 {
    if count == 0u || max_count == 0u {
        return 0.0;
    }

    if transform_id == 0u {
        return clamp(f32(count) / f32(max_count), 0.0, 1.0);
    }

    let count_scale = log(f32(count) + 1.0);
    let max_count_scale = log(f32(max_count) + 1.0);
    return clamp(count_scale / max_count_scale, 0.0, 1.0);
}
```

#### Migration Notes

- Existing default visual behavior remains log1p.
- Existing renderer constructors should keep compiling after adding default
  encoding in `new()`.
- Evidence v1/v2 shapes do not change in this task.
- Workbench transform changes require density recomputation; they must not
  silently relabel existing pixels.

#### Misinterpretations To Prevent

- Wrong interpretation: add a label that says "log1p" but leave render config
  unchanged.
  Correct rule: the active transform must be carried through renderer config and
  WGSL params.
- Wrong interpretation: implement rank/equalized by pretending log1p is close
  enough.
  Correct rule: equalized/rank is deferred until T006 aggregate metadata exists.
- Wrong interpretation: use benchmark-style UI to show transform performance.
  Correct rule: show encoding semantics only, no timings or throughput.
- Wrong interpretation: put density encoding types in `rawscope-data`.
  Correct rule: encoding belongs to `rawscope-render`; data loading does not own
  visual color semantics.

#### Invariants

- Default scatter and timeline transforms remain `Log1p`.
- `DensityTransform::Linear` maps `max_count` to `1.0`.
- `DensityTransform::Log1p` maps `max_count` to `1.0`.
- Empty bins and zero max count map to `0.0`.
- UI state must reflect the same transform sent to the renderer.
- Palette labels and swatches must match the active renderer palette.
- This task must not alter GPU density count computation.
