### T003 - Add Marginal And Overview Context Summaries

#### Objective

Add compact context summaries that help analysts see distribution shape around
the main density surface: scatter x/y marginals, timeline lane/time marginals,
and a timeline overview strip showing current viewport against the full range.

#### Scope

- Create `crates/rawscope-render/src/view_summaries.rs`.
- Add CPU/reference marginal summary functions for current scatter and timeline
  records.
- Add a timeline overview context that records full time range, current time
  range, bucket counts, and current viewport fraction.
- Add workbench UI projection and a restrained egui display for marginals and
  timeline overview.
- Recompute summaries when the active dataset or viewport changes.

#### Out of Scope

- Do not add GPU marginal computation.
- Do not add a draggable mini-map in this task.
- Do not add arbitrary dashboard panels.
- Do not add dataset diff; T008 owns diff.
- Do not add benchmark claims or performance UI.

#### Blocked By

T001, T002

#### Why It Is Blocked

Marginals and overview need the encoding context from T001 and the view/lane
context from T002 so the added summaries reinforce the same visual semantics
instead of becoming disconnected panels.

#### Implementation Details

Create `crates/rawscope-render/src/view_summaries.rs`:

```rust
//! CPU summary tracks for density view context.

use rawscope_core::{F32Range, U64Range};
use rawscope_data::{ScatterPointRecord, TimelineEventRecord};

#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub struct SummaryBin {
    pub index: u32,
    pub count: u32,
}

#[derive(Debug, Clone, PartialEq, Eq)]
pub struct ScatterMarginalSummary {
    pub x_bins: Vec<SummaryBin>,
    pub y_bins: Vec<SummaryBin>,
    pub max_x_count: u32,
    pub max_y_count: u32,
}

#[derive(Debug, Clone, PartialEq, Eq)]
pub struct TimelineMarginalSummary {
    pub time_bins: Vec<SummaryBin>,
    pub lane_bins: Vec<SummaryBin>,
    pub max_time_count: u32,
    pub max_lane_count: u32,
}

#[derive(Debug, Clone, Copy, PartialEq)]
pub struct TimelineOverviewWindow {
    pub start_fraction: f32,
    pub end_fraction: f32,
}

#[derive(Debug, Clone, PartialEq, Eq)]
pub struct TimelineOverviewSummary {
    pub full_time_range: U64Range,
    pub current_time_range: U64Range,
    pub time_bins: Vec<SummaryBin>,
    pub max_time_count: u32,
}

impl TimelineOverviewSummary {
    pub fn current_window(&self) -> TimelineOverviewWindow;
}

pub fn scatter_marginal_summary(
    points: &[ScatterPointRecord],
    x_range: F32Range,
    y_range: F32Range,
    x_bin_count: u32,
    y_bin_count: u32,
) -> ScatterMarginalSummary;

pub fn timeline_marginal_summary(
    events: &[TimelineEventRecord],
    time_range: U64Range,
    lane_count: u32,
    time_bin_count: u32,
) -> TimelineMarginalSummary;

pub fn timeline_overview_summary(
    events: &[TimelineEventRecord],
    full_time_range: U64Range,
    current_time_range: U64Range,
    time_bin_count: u32,
) -> TimelineOverviewSummary;
```

Rules:

- Marginals must ignore records outside the requested range.
- Timeline lane bins are indexed by lane id and have one bin per lane.
- Summary bin vectors must be stable length for a fixed bin count.
- `TimelineOverviewWindow` fractions must be clamped to `0.0..=1.0`.
- Use saturating `u32` counts if a bin count would exceed `u32::MAX`.

#### Migration Notes

- Existing density rendering remains unchanged.
- Existing evidence v1/v2 artifacts remain unchanged until T007.
- Workbench state gains derived summaries; they can be rebuilt and do not need
  persistence.

#### Misinterpretations To Prevent

- Wrong interpretation: add a second charting panel with arbitrary charts.
  Correct rule: only fixed marginal/overview context for existing density views.
- Wrong interpretation: use marginals as evidence replacement.
  Correct rule: marginals explain shape; row evidence remains selected-row
  drilldown/export.
- Wrong interpretation: add GPU compute for marginals now.
  Correct rule: CPU/reference summaries first.
- Wrong interpretation: add interactive mini-map navigation.
  Correct rule: overview is read-only in this task.

#### Invariants

- Marginal summaries are deterministic for the same records, ranges, and bin
  counts.
- Bins outside the requested range do not count records.
- Timeline overview window always represents current range relative to full
  range.
- Summary UI does not alter brush, pan, zoom, selection, or evidence state.
