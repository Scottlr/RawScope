### T003 - Add Adaptive Resolution And Derived-Field Resource Policy

#### Objective

Choose deterministic visual-field grid tiers from physical plot size, WGPU
limits, and the existing generation resource budget, and account every derived
field without adding pointer-time allocation or dispatch.

#### Scope

- Add render-owned validated resolution policy and decisions for preview/exact
  continuous 2D fields.
- Select only named short-axis tiers and derive checked workgroup-aligned
  rectangular grids from physical plot aspect under device/resource limits;
  never allocate directly from arbitrary viewport dimensions.
- Extend existing generation resource estimates with count double buffers,
  palette LUTs, category layers, ridge fields, previous transition fields,
  readback staging, and bind/pipeline-owned allocations.
- Extend final render coordinator intents with visual-field mapping/mode/quality
  identity and stale-result protection.
- Coalesce resize/pan/zoom requests; pointer handlers submit intents only.
- Surface explicit `ResolutionDecisionReason` for evidence/UI/benchmarks without
  exposing shader knobs.

#### Out of Scope

- No palette, composition, ridge, contour, point, or comparison behavior.
- No default RAM/VRAM budget choice from unreviewed measurements.
- No runtime auto-tuning based on instantaneous frame rate.
- No unit-test timing thresholds or new benchmark claims.

#### Implementation Details

Create:

```rust
#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub struct VisualResolutionPolicy {
    preview_tiers: &'static [VisualResolutionTier],
    exact_tiers: &'static [VisualResolutionTier],
    target_physical_pixels_per_bin: NonZeroU8,
    max_exact_bins: NonZeroU64,
}

#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub struct VisualResolutionTier {
    pub quality: VisualFieldQuality,
    pub short_axis_bins: NonZeroU16,
    pub dimension_alignment_bins: NonZeroU8,
    pub max_total_bins: NonZeroU64,
}

#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub struct VisualResolutionDecision {
    pub grid: GridSize,
    pub quality: VisualFieldQuality,
    pub reason: ResolutionDecisionReason,
}

#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub enum ResolutionDecisionReason {
    PlotMatched,
    DeviceLimited,
    ResourceBudgetLimited,
}

#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub struct VisualFieldResourceEstimate {
    pub coordinate_bytes: u64,
    pub channel_bytes: u64,
    pub count_field_bytes: u64,
    pub derived_field_bytes: u64,
    pub transition_bytes: u64,
    pub staging_bytes: u64,
}
```

Default candidate short-axis tiers are domain constants near the resolution
owner, for example 128, 256, 512, and 1024 bins. Derive the long axis from the
physical plot aspect ratio, round it with checked arithmetic to the tier's
workgroup alignment, and reject/lower it before exceeding the tier, device, or
resource bin cap. Human review chooses the final preview/exact lists; code must
not assume every device admits every tier.

`choose_visual_resolution(plot_size_px, policy, device_limits, remaining_budget)`
uses checked aspect/dimension/bin/byte arithmetic and returns a typed error when
no minimum tier fits. Degenerate/zero physical plot sizes are rejected rather
than producing a one-bin accidental allocation.
The selected exact grid stays fixed for one settled generation. During resize or
gesture, reproject the compatible settled field; submit at most one latest
preview and one latest exact intent through the final coordinator.

Extend coordinator identity with mapping/mode:

```rust
pub struct VisualFieldIntent {
    pub dataset_generation: DatasetGeneration,
    pub cohort_generation: CohortGeneration,
    pub view_generation: VisualFieldViewGeneration,
    pub mapping: VisualFieldMapping,
    pub mode: VisualFieldMode,
    pub resolution: VisualResolutionDecision,
}
```

Use the existing active/pending/retiring resource plan. Each render module
returns its own checked estimate; one aggregate sums it. Do not move allocation
ownership into the budget module.

Allowed pressure responses are explicit: choose a lower named tier before
allocation, disable an optional prior transition field, or report a mode
unavailable. Never drop category layers, rows, or exact evidence silently.

#### Migration Notes

- Preserve current 128/256 behavior where the new default decision selects
  those tiers; intentional changes require benchmark/human review.
- Exact field/evidence records the chosen grid.
- Remove old anonymous constants after all callers migrate; do not keep two
  quality policies.

#### Misinterpretations To Prevent

- Wrong interpretation: use one bin per screen pixel or force a square grid.
  Correct rule: choose a named short-axis tier and a checked aspect-aware grid
  under device/resource limits.
- Wrong interpretation: recompute on every resize/mouse move. Correct rule:
  pointer/resize code submits coalesced intents and reprojects settled output.
- Wrong interpretation: reduce hidden category layers to fit memory. Correct
  rule: reject/unavailable is preferable to changing meaning.
- Wrong interpretation: add a second visual-only budget. Correct rule: derived
  estimates feed the existing generation admission plan.

#### Invariants

- All grid/bin/byte arithmetic is checked before allocation.
- Resolution decisions are deterministic for the same inputs.
- Rectangular grids approximate physical plot aspect within the documented
  alignment tolerance without exceeding caps.
- One exact generation uses one immutable grid.
- Every simultaneously live derived/transition/staging resource is accounted.
- Pointer handlers allocate, dispatch, scan, map, and wait for nothing.
- Stale mapping/mode/resolution completions cannot publish.

#### Acceptance Criteria

- [ ] Named preview/exact tiers replace hard-coded workbench grid constants.
- [ ] Wide/tall plots receive bounded aspect-aware grids rather than square-only
      allocations.
- [ ] Device and resource limits can lower/reject a tier before allocation.
- [ ] Derived resources contribute to active/pending/retiring peak accounting.
- [ ] Render intents include mapping, mode, grid, and full generation identity.
- [ ] Pan/zoom/resize requests coalesce without pointer-time GPU/row work.
- [ ] Focused policy/coordinator/resource tests, formatting, and workspace check
      pass.
