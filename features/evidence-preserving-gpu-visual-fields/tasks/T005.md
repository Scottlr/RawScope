### T005 - Add Exact Mass Contours And Axis-Integrated Marginals

#### Objective

Turn arbitrary transformed-intensity contours and detached summary strips into
exact tied mass thresholds and marginals derived once from the settled count
field and composed directly with the plot axes.

#### Scope

- Add analysis-owned mass-fraction, mass-contour, and density-marginal contracts.
- Derive requested mass thresholds and X/Y marginals from one exact settled
  `DensityCountGrid` returned by the shared asynchronous readback.
- Record actual enclosed row counts/fractions after equal-count bin ties.
- Replace topographic/relief intensity-period contours with count-threshold
  contours supplied by the settled generation.
- Draw X and Y marginal silhouettes inside dedicated stable axis gutters using
  active field color; comparison overlays are added by T010.
- Keep previous compatible contour/marginal context during interaction and mark
  it refining/stale until one settled snapshot replaces it.

#### Out of Scope

- No row/source rescans, second GPU readback, approximate percentile label,
  statistical confidence interval, KDE bandwidth control, or arbitrary contour
  editor.
- No comparison overlay, category share marginal, or timeline lane marginal.
- Do not move axis numeric/tick truth back into render/workbench.

#### Implementation Details

Create:

```rust
#[derive(Debug, Clone, Copy, PartialEq, Eq, PartialOrd, Ord)]
pub struct MassFractionBasisPoints(u16);

#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub struct MassContourLevel {
    pub requested: MassFractionBasisPoints,
    pub minimum_bin_count: Option<NonZeroU32>,
    pub enclosed_row_count: u64,
    pub total_row_count: u64,
}

#[derive(Debug, Clone, PartialEq, Eq)]
pub struct MassContourSet {
    pub levels: Arc<[MassContourLevel]>,
}

#[derive(Debug, Clone, PartialEq, Eq)]
pub struct DensityMarginals {
    pub x_counts: Arc<[u64]>,
    pub y_counts: Arc<[u64]>,
    pub max_x_count: u64,
    pub max_y_count: u64,
}

#[derive(Debug, Clone)]
pub struct SettledDensityContext {
    pub field_generation: VisualFieldViewGeneration,
    pub counts: Arc<DensityCountGrid>,
    pub contours: MassContourSet,
    pub marginals: DensityMarginals,
}
```

`MassFractionBasisPoints::try_new` accepts 1..=10_000. The reviewed default set
is `[5_000, 8_000, 9_500, 9_900]`. Human review may adjust it before
implementation; literals live beside this domain, not in UI.

Algorithm:

1. Sum total rows with checked `u64` arithmetic.
2. Compute each target as `ceil(total * basis_points / 10_000)` with checked
   `u128` intermediate arithmetic.
3. Build a histogram of nonzero bin count -> number of bins.
4. Traverse counts descending and accumulate `count * bin_frequency`.
5. For each requested fraction, select the count threshold where cumulative
   mass reaches/exceeds the target.
6. Record the full tied threshold mass, not an invented exact fraction.

For a zero-total grid, retain each requested level with `minimum_bin_count =
None` and zero actual/total counts. The shader skips absent thresholds; it must
not treat zero as a contour over empty cells.

Marginals sum the same grid by axis with checked arithmetic. Shader uniforms
carry up to the fixed reviewed contour count and raw count thresholds. Smooth
presentations may interpolate counts before thresholding, but labels/evidence
use the discrete tied mass result.

Axis gutters get stable dimensions from `PlotSurfaceLayout`. The X silhouette
grows inward from the bottom axis and Y silhouette grows inward from the left;
they never resize the plot after allocation. Hover/brush hit testing continues
to use the authoritative plot rectangle, excluding marginal gutters.

#### Misinterpretations To Prevent

- Wrong interpretation: map intensity levels to labels like 50%. Correct rule:
  mass labels come from exact tied count accumulation.
- Wrong interpretation: read counts once per consumer. Correct rule: one settled
  `Arc<DensityCountGrid>` feeds inspection, marginals, contours, and evidence.
- Wrong interpretation: marginal bars may overlap or change plot size. Correct
  rule: stable dedicated gutters are part of plot layout.
- Wrong interpretation: hide tie overshoot. Correct rule: actual enclosed count
  is recorded and inspectable.

#### Invariants

- Contour and marginal generation matches one exact field generation/grid.
- Summed X and Y marginals both equal total grid row count.
- Requested mass levels are ordered/unique and actual mass never understates the
  request due to hidden ties.
- Empty fields have no drawable threshold and cannot outline zero-count cells.
- No additional row scan or readback is introduced.
- Plot geometry and pointer mapping remain unchanged by gutter drawing.
