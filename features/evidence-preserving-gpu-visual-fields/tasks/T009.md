#### Objective

normalized purity, and expose exact per-cell shares through the existing focus
lens, tooltip, pin, and semantic point-reveal paths.

#### Implementation Details

Create analysis formula types:

```rust
#[derive(Debug, Clone, Copy, PartialEq)]
pub struct CompositionCellSummary {
    pub total_count: u64,
    pub dominant_layer: Option<CategoryLayerId>,
    pub dominant_share: f64,
    pub normalized_entropy: f64,
    pub purity: f64,
}

pub fn summarize_composition_cell(
    layer_counts: &[u32],
) -> Result<CompositionCellSummary, CompositionError>;
```

Let `k` be the fixed visible layer count in this generation's T007 plan, not the
number occupied in one cell. For `k > 1`, compute
`H = -sum(p_i * ln(p_i))`, treating zero-share terms as zero, and
`purity = 1 - H / ln(k)`. For a one-layer plan with rows, purity is 1. For empty
cells, dominant is `None`, shares are zero, and purity is zero. Dominant ties
resolve by stable `CategoryLayerId`, and tooltip marks the equal top shares
rather than implying a unique statistical winner.

WGSL samples each layer count at the same field coordinate, computes total and
composition, selects the discrete dominant category LUT entry, and mixes toward
the reviewed neutral mixed color by `1 - purity`. Density intensity controls
final luminance/visibility. The UI legend separately explains category hue,
density lightness, and mixed-to-pure saturation.

Extend inspection with:

```rust
pub struct CompositionInspectionDetail {
    pub layers: Arc<[CompositionLayerShare]>,
    pub dominant_layer: Option<CategoryLayerId>,
    pub purity: f64,
    pub accuracy: CategoryIndexAccuracy,
}

pub struct CompositionLayerShare {
    pub layer_id: CategoryLayerId,
    pub label: Arc<str>,
    pub count: u32,
    pub share: f64,
}
```

Layer list is bounded by T007. Inspection derives from settled layer readback and
uses direct bin indexing. During refining/no readback, retain compatible settled
detail with freshness state or omit it explicitly; never scan rows.

#### Misinterpretations To Prevent

- Wrong interpretation: weighted-average category RGB values. Correct rule:
  dominant layer selects a real discrete hue; purity controls neutral mixing.
- Wrong interpretation: purity equals dominant share. Correct rule: use the
  documented fixed-visible-layer normalized entropy formula and report both
  values.
- Wrong interpretation: hover may read GPU/source data. Correct rule: direct
  lookup in one settled bounded cache only.
- Wrong interpretation: interpolation creates exact category membership between
  cells. Correct rule: focus/tooltip use exact cells and presentation is labelled
  reconstructed field context.

#### Invariants

- Total density remains the exact active cohort count field.
- Composition layer counts sum to total for every inspected cell.
- Hue always names a real visible layer.
- Purity is finite, bounded 0..=1, and CPU/GPU-consistent.
- Other/Missing/Invalid labels remain explicit.
- Hover cost is O(visible layer count), never O(rows) or O(all bins).
- Point reveal sampling/status is unchanged by category coloring.
