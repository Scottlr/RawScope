### T012 - Add Multiscale Density Ridge Analysis

#### Objective

Define a bounded, deterministic CPU reference for fine/medium/coarse ridges of a
smoothed scalar count field, exposing undirected local orientation and strength
without inventing paths, clusters, or motion.

#### Scope

- Add analysis-owned closed ridge scales and validated configuration.
- Smooth exact count grids with small fixed separable kernels selected by scale.
- Compute the symmetric Hessian, ordered eigenvalues, a discrete height-ridge
  local-maximum condition across the minor-eigenvector direction, local ridge
  strength, and an undirected tangent orientation.
- Apply explicit edge, empty-grid, non-finite, and normalization rules.
- Return immutable generation/config-tagged CPU ridge fields for GPU parity,
  inspection explanation, evidence, and fallback validation.
- Define scale and minimum-strength defaults as reviewed named constants near
  the ridge domain owner.
- Keep all formulas free of GPU, serde, UI, and dataset profile concepts.

#### Out of Scope

- No streamline integration, vector flow, LIC texture, particles, trajectories,
  path extraction, connected-component clustering, skeleton graph, topology,
  watershed, or causal interpretation.
- No arbitrary kernel editor, user-authored convolution, unbounded scale count,
  or broad numerical dependency.
- No renderer, shader, controls, or evidence wire in this task.

#### Implementation Details

Add closed analytical contracts:

```rust
#[derive(Debug, Clone, Copy, PartialEq, Eq, Hash)]
pub enum RidgeScale {
    Fine,
    Medium,
    Coarse,
}

#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub struct RidgeConfig {
    pub scale: RidgeScale,
    pub minimum_strength_basis_points: u16,
    pub minimum_anisotropy_basis_points: u16,
}

#[derive(Debug, Clone, Copy, PartialEq)]
pub struct RidgeCell {
    pub strength: f32,
    pub tangent_x: f32,
    pub tangent_y: f32,
}

#[derive(Debug, Clone, PartialEq)]
pub struct DensityRidgeField {
    pub width: u32,
    pub height: u32,
    pub config: RidgeConfig,
    pub cells: Arc<[RidgeCell]>,
}

pub fn derive_density_ridges(
    counts: &DensityCountGrid,
    config: RidgeConfig,
) -> Result<DensityRidgeField, RidgeError>;
```

Use reviewed fixed normalized Gaussian/binomial separable kernels whose radii
are candidates `1`, `2`, and `4` cells for fine, medium, and coarse at the
selected exact grid. Record exact coefficients, effective sigma/radius, grid,
and boundary rule; scale names do not claim identical physical width across
different resolution tiers.

Treat the field domain as normalized UV coordinates. Use centered finite
differences where available and one documented reflected/clamped edge rule
elsewhere, with derivative spacing derived from grid dimensions. For Hessian
`[[dxx, dxy], [dxy, dyy]]`, derive ordered eigenvalues
`lambda_min <= lambda_max` and the unit minor eigenvector analytically.

A discrete height-ridge candidate must satisfy all of these:

1. `lambda_min < 0`, so curvature is locally concave across the ridge.
2. The center smoothed value is at least both bilinearly sampled values one cell
   in the positive/negative minor-eigenvector direction and strictly exceeds at
   least one, approximating the continuous zero normal-derivative condition.
3. Normalized eigengap anisotropy
   `abs(lambda_max - lambda_min) / (abs(lambda_max) + abs(lambda_min) + epsilon)`
   meets the configured basis-point cutoff, preventing arbitrary orientation at
   isotropic peaks/crossing centers.

Use raw strength `sigma^2 * max(-lambda_min, 0)` for candidates, normalize by
the maximum raw strength in this field generation/config, then apply the
strength basis-point cutoff. Empty/zero maxima produce zero strength. Record
epsilon and all normalization rules as named versioned formula constants.

Store the tangent as the unit vector perpendicular to the selected normal.
Canonicalize its sign (`x > 0`, or `x == 0 && y >= 0`) solely for deterministic
bytes/tests. Product language must still call it undirected: `(x, y)` and
`(-x, -y)` represent the same ridge orientation. Tangents remain in normalized
field coordinates; T013 applies the plot-space Jacobian before drawing.

#### Misinterpretations To Prevent

- Wrong interpretation: tangent vectors describe row movement. Correct rule:
  they describe local undirected geometry of a smoothed aggregate field.
- Wrong interpretation: one ridge is a cluster. Correct rule: no membership or
  connected component is inferred.
- Wrong interpretation: strength compares unrelated datasets/configurations.
  Correct rule: it is normalized within the documented field generation/scale.
- Wrong interpretation: more scales may be generated dynamically. Correct rule:
  the mode has three reviewed closed scales.

#### Invariants

- The input exact count grid is never modified.
- Output dimensions and cell order exactly match the input grid.
- Strength and tangent values are finite; strength is bounded 0..=1.
- Non-zero tangents are unit length within documented tolerance.
- Isotropic cells below the eigengap cutoff have no invented orientation.
- Orientation sign is deterministic but semantics remain undirected.
- Flat/empty fields produce zero strength and no invented direction.
- Analysis remains GPU-, serde-, UI-, and dependency-profile-free.
