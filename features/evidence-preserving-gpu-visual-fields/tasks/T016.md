### T016 - Add Visual Field Evidence V1 And Report Integration

#### Objective

Add one canonical, versioned evidence artifact for generic visual-field
projection and mode semantics, preserving all legacy scatter/timeline artifacts
and keeping serialization out of analysis/data/render ownership.

#### Scope

- Extend canonical evidence with a validated generic visual-field context built
  from stable analytical/controller state and settled generation metadata.
- Add a new `rawscope.visual-field-evidence` v1 artifact covering numeric-pair
  and time-value mappings plus density, composition, comparison, and ridge modes.
- Record row-count aggregation, source/cohort identity, typed domains, grid and
  quality decisions, transforms/normalization/palette identity, freshness, and
  exact-versus-derived presentation semantics.
- Project canonical selection identity, exact selected-row count, selected bins,
  bounded row sample, and source-row availability from `EvidenceDocument`; add
  optional exact pinned-cell detail only when its generation matches.
- Record requested/actual mass contours, marginal totals, semantic point sample
  status, category layers/accuracy/purity formula, comparison formula/support/
  split, time quantization, and ridge scale/formula as applicable.
- Add the artifact to report manifests/bundles through canonical evidence APIs.
- Preserve every landed legacy scatter v1-v6 and timeline v1-v4 decoder and its
  byte-stable writer behavior for safely representable inputs.
- Make legacy writers reject unrepresentable new modes with a typed error rather
  than silently dropping semantics.

#### Out of Scope

- No screenshots, GPU buffers, shader source, egui state, window layout,
  transient hover location, arbitrary user prose, or source data payload.
- No serde derive in `rawscope-analysis`, `rawscope-data`, or `rawscope-render`.
- No mutation of legacy schema IDs, field meanings, version bytes, or decoders.
- No claim of significance, clustering, flow, trajectory, or complete point
  display when those semantics are not true.

#### Why It Is Blocked

Evidence must describe stable shipped semantics, not anticipated UI labels or
shader internals. Every mode, session binding, quality decision, and inspection
disclosure must be settled before its canonical wire contract is frozen.

#### Implementation Details

Add canonical validated types with private fields/constructors following the
evidence crate's landed pattern. The wire surface is conceptually:

```rust
pub const VISUAL_FIELD_EVIDENCE_V1_SCHEMA: &str =
    "rawscope.visual-field-evidence";

#[derive(Debug, Clone, PartialEq, Serialize, Deserialize)]
#[serde(tag = "kind", rename_all = "snake_case")]
pub enum VisualFieldProjectionEvidenceV1 {
    NumericPair { x: FieldEvidenceV1, y: FieldEvidenceV1 },
    TimeValue { time: FieldEvidenceV1, value: FieldEvidenceV1 },
}

#[derive(Debug, Clone, PartialEq, Serialize, Deserialize)]
#[serde(tag = "kind", rename_all = "snake_case")]
pub enum VisualFieldModeEvidenceV1 {
    Density(DensityModeEvidenceV1),
    CategoryComposition(CategoryCompositionEvidenceV1),
    CohortComparison(CohortComparisonEvidenceV1),
    DensityRidges(DensityRidgeEvidenceV1),
}

#[derive(Debug, Clone, PartialEq, Serialize, Deserialize)]
pub struct VisualFieldEvidenceV1 {
    pub schema: EvidenceSchemaVersion,
    pub source: SourceEvidenceV1,
    pub projection: VisualFieldProjectionEvidenceV1,
    pub category: Option<FieldEvidenceV1>,
    pub aggregation: RowCountAggregationEvidenceV1,
    pub cohort: CohortEvidenceV1,
    pub field: ExactFieldEvidenceV1,
    pub presentation: VisualFieldModeEvidenceV1,
    pub selection: SelectionEvidenceV1,
    pub pinned_cell: Option<VisualFieldPinnedCellEvidenceV1>,
    pub provenance: VisualFieldProvenanceEvidenceV1,
}
```

Reuse canonical evidence value types rather than duplicating wire types where
the meanings match. Names above are contracts to refine against the existing
crate, not permission to create broad `types.rs`/`models.rs` files.

Required semantic fields include:

- Selection: canonical selection ID, exact selected count, selected bins, bounded
  row/evidence-key sample with completeness/limit disclosure, and source-row
  availability. It adapts `EvidenceDocument`; it never recomputes membership.
- Pinned cell when present: generation-matched bin/domain bounds, exact total,
  and the applicable composition/comparison detail from settled inspection.
- Projection: stable column identity/display name/kind, exact typed domains,
  missing/invalid/projected counts, and time normalization/quantization for
  time-value.
- Exact field: dimensions, bin rules, exact row-count aggregation, eligible/
  counted totals, dataset/cohort/mapping/generation identity, selected quality
  tier and reason, plus settled/reprojected freshness.
- Density context: transform, normalization, palette ID/version, requested and
  actual contour mass counts/fractions, marginal totals, and semantic zoom
  eligible/rendered/sample-complete disclosure.
- Composition: ordered visible category layers including Other/Missing/Invalid,
  canonical typed value plus display label for value layers, index accuracy,
  dominant real-layer rule, fixed visible-layer count used by the normalized
  entropy/purity formula, and total-density/lightness semantics.
- Comparison: baseline/active cohort identities and totals, exact normalized
  share-delta formula, equal-cohort support-share formula, shared density/delta/
  support maxima, and signed/split state with split fraction when used.
- Ridges: selected closed scale, fixed kernel/formula version, strength cutoff/
  normalization, anisotropy cutoff, discrete height-ridge local-maximum rule,
  undirected normalized-field orientation statement, and source field identity.

Evidence construction accepts immutable snapshots from analysis/controller/
coordinator owners and validates cross-generation consistency. It must fail if
counts, mapping, category plan, comparison pair, or derived mode identity do not
match the published field. Deterministic serialization uses stable layer/order
rules and rejects non-finite values.

Legacy conversion is explicit. A generic numeric-pair density state may be
representable by the latest legacy scatter writer only when every required old
semantic exists and no new meaning would be lost. Time-value, composition, split
comparison, and ridges return `EvidenceConversionError::Unrepresentable` for
legacy writers.

#### Before / After

**Before:** new generic modes can look correct but lack one stable artifact that
explains exactly what pixels, counts, samples, and approximations mean.

**After:** reports can carry a canonical, deterministic visual-field record
without coupling evidence to a dataset profile or renderer implementation.

#### Migration Notes

- Preserve all landed legacy fixtures byte-for-byte; add new fixtures rather
  than updating old expected files.
- Extend `EvidenceDocument` additively with validated visual context; keep
  existing pattern matches/exhaustiveness changes deliberate.
- Session provenance may be referenced/copied as stable source/mapping intent,
  but evidence remains canonical and independently validated.
- Version palette/formula identifiers when semantics change; shader refactors
  that preserve semantics do not require evidence churn.

#### Misinterpretations To Prevent

- Wrong interpretation: evidence is a screenshot recipe. Correct rule: it
  records analytical/presentation semantics and provenance, not UI pixels.
- Wrong interpretation: reprojected preview is exact settled evidence. Correct
  rule: freshness/quality state is explicit and export policy must require the
  appropriate settled snapshot.
- Wrong interpretation: category purity or comparison support is confidence.
  Correct rule: formulas and labels state exactly what they measure.
- Wrong interpretation: ridge tangent is direction. Correct rule: evidence says
  undirected local scalar-field orientation.

#### Invariants

- Canonical evidence validates all cross-generation/mapping/cohort identities.
- Selection membership/sample remains canonical and pinned detail cannot attach
  across generations.
- Serialization is deterministic, finite, ordered, and versioned.
- Legacy readable inputs and safely representable writers remain byte-stable.
- New semantics cannot be downgraded by omission.
- Evidence/report owns serde; analysis/data/render remain serialization-free.
- No artifact claims weighted aggregation, significance, trajectory, cluster,
  or complete point display unless the recorded facts support it.
- Report bundles reference the canonical artifact kind and preserve provenance.
